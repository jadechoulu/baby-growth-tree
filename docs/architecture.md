# 小芽站点架构与设计原则

更新：2026-10-28。本文是随源码维护的长期约定，适用于所有同级分类。具体改造与验收契约见 [共享站点框架方案](../.rich-harness/tasks/unified-site-shell/spec/tech-design.md)。

## 当前状态

当前已合并为单仓库、单站点，拥有共同首页和相对路径互跳；成长与英语仍分别实现侧栏、移动目录和详情框架。本文的共享框架为本次推荐目标，**尚未实现、尚未上线**，不能据此宣称改造完成。实施后同步更新本节与 README。

## 一个网站，多个分类

小芽是全科启蒙与成长陪伴网站。成长技能树、英语启蒙是平级分类，而不是两个独立网站。全站首页用于选择分类，分类内部完成具体阅读与记录。

| 层次 | 负责 | 不承担 |
| --- | --- | --- |
| 站点框架 | 分类注册、首页入口、全局切换、局部导航容器、移动目录、快捷栏、焦点与基础阅读样式 | 月龄定位、路线等价判断、技能进阶、素材推荐、记录保存 |
| 分类接入层 | 当前标题、目录项、选中状态、内容节点、业务动作、主题 ID | 复制框架的 DOM、断点与事件处理 |
| 领域内容 | 成长图谱与技能记录；英语路线、素材、儿歌及资料出处 | 修改其他分类的数据或接管站点导航 |

框架采用轻量静态多页面方式，不更换既有领域模型，不引入必须在线请求的导航配置。所有分类共同使用一份导航实现和一套布局变量。

## 分类与路径

| 分类 ID | 标题 | 保留入口 | 主题 |
| --- | --- | --- | --- |
| `home` | 小芽首页 | `home.html` | 中性色 |
| `growth` | 成长技能树 | `index.html` | 成长主题 |
| `english` | 英语启蒙 | `english/index.html#routes` | 英语主题 |

目标注册表放在 `shared/site-sections.json`。每项含稳定 ID、标题、相对站点根的入口、主题 ID、图标 ID、简介。首页卡片与所有分类切换入口读取同一注册表。新增分类不提供空白占位入口；待内容可访问时再注册。

所有内部导航生成相对路径，显式传入当前页面到站点根的路径。根入口为 `./`，英语为 `../`，单文件导出为 `../../`。不能通过猜测域名、路径长度或 GitHub 账户定位根目录。

注册新分类时还需实现该分类内容入口并接入框架、更新构建清单和主题、完成两旧分类互跳及移动端验收。注册表统一解决导航扩展，不替代业务内容开发。

## 共用交互

顶部站点栏始终保留“小芽首页”和“当前分类 ▾”；长页面滚动时仍可达。桌面侧栏列当前分类目录，窄屏改为同一套可展开目录，抽屉中同时提供所有分类及当前分类完整目录。

窄屏底部快捷栏只提供当前分类最常用的三至五项；成长与英语可传入不同项，但使用同一组件和选中规则。完整目录、路线子项和阶段列表留在目录中，不要求所有分类拥有同样的业务名称或数量。

详情和预览的标题栏同样放置共享分类切换按钮。分类选择器可在当前弹层之上打开；取消后恢复原详情、输入值和焦点，不能为打开导航而销毁表单。选择另一分类后使用正常链接离开，沿用现有保存保护。

目录与分类选择使用原生 `dialog` 管理模态和焦点。一个时刻仅有一个框架导航弹层；可以位于领域详情弹层之上。所有关闭路径统一清理滚动锁、监听器与 `aria-expanded`。不把框架目录复用为业务表单容器。

## 主题与阅读规则

框架统一字体、字号、间距、容器、断点、圆角、层级、触控和安全区。分类通过 `data-site-section` 和主题变量覆盖强调色、浅底、边框及图标色；颜色之外保留文字、图标或线型表达状态。

导航使用 `900px` 单一断点，图表自行决定显示方式。窄屏不是桌面内容改成一列：先呈现当前任务、当前阶段与摘要，完整证据、套系和参考资料按需展开。保留“查看完整内容”的路径，折叠摘要须说明里面是什么。

| 场景 | 窄屏阅读方式 |
| --- | --- |
| 宝宝视角 | 当前阶段与主要活动优先；参考说明收纳；资料编辑入口可达 |
| 阶段与路线 | 先看一个阶段；前后切换；其他路线先显示对应摘要，再展开完整资料 |
| 素材图鉴 | 搜索和类型常驻；其他筛选展开；显示生效条件及结果数；分批阅读 |
| 成长技能清单 | 先选阶段与领域；优先看当前任务/状态；不把全部阶段清单堆在首屏 |
| 图谱与关系 | 保留聚焦链路；手机提供关系列表/逐条脉络；整图作为可放大入口 |
| 详情与原图 | 详情摘要和主要动作优先；长套系、引用折叠；图片独立预览与缩放 |

正文至少 `15px`、辅助说明至少 `12px`、输入控件至少 `16px`，主要触控目标至少 `44×44px`。在 `320px` 宽度也不能缩小文字或把按钮挤出屏幕。窄屏避免双重粘性工具栏占满首屏，固定底栏留出内容与软键盘空间。

## 状态与兼容

框架仅管理导航开关、焦点与布局模式等临时状态。筛选、当前阶段、图谱焦点、阅读展开、宝宝档案和记录各由所属分类维护。共享外观不表示数据可以自动合并。

成长保留 IndexedDB `xiaoya-growth`、旧记录 `xiaoya-growth-v1` 及查看偏好 `xiaoya-growth-view-v1`；英语保留 `little-leaf-english-v1`。个人生日、词汇、手记和收藏不得成为公开默认值或框架配置。

继续支持既有根地址、英语 hash、浏览器后退、单文件导出和 JSON 备份。不得用替换根入口、改存储来源或新增强制登录来完成框架统一。

## 构建与维护

推荐共享文件为 `shared/site-sections.json`、`shared/site-shell.js` 和 `site.css`。根页面与首页载入共享运行时，英语构建将同一份注册表、运行时和样式内联，以保留离线单文件能力。生成 HTML 不作为独立维护源。

统一发布仍走 `scripts/build-site.mjs`，输出 `dist/site`。运行时文件按白名单进入发布包；`AGENTS.md`、本文件、方案和测试保存在 `main`，不复制到 `codex/pages` 网站包。发布副本只接收构建结果，不在副本开发。

每次框架修改同时验收成长、英语、首页、详情与预览，覆盖窄屏、断点两侧和宽屏；保留状态与未保存行为。方案、实现状态和验收证据分开记录，不用设计目标充当通过证据。
