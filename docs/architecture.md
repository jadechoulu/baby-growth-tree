# 小芽站点架构与设计原则

更新：2026-11-03。本文是随源码维护的长期约定，适用于所有同级分类。具体改造与验收契约见 [共享站点框架方案](../.rich-harness/tasks/unified-site-shell/spec/tech-design.md)。

## 当前状态

已实现单仓库、单站点、共享分类注册与导航运行时。首页、成长和英语共用站点栏、侧栏、窄屏目录及快捷栏；详情与预览共用分类选择器。旧地址与英语离线构建保持兼容。验收记录独立保存，具体浏览器与设备覆盖不由本设计文档代替。

## 成长分类的内容版本

2026-10-30 新增卫健委版本，本批已获用户发布授权，Netlify 新观察接口已先部署；网页经任务 PR 的 verify 和 main 统一 Pages 工作流发布，实际状态以 Actions 为准。本次方案与验收入口见 [卫健委版实现契约](../.rich-harness/tasks/health-standard/plan.md)。成长仍是一个全站分类，版本在分类内部切换：原 `index.html` 明确为毛老师版，新 `health.html` 读取 WS/T 580—2017。两个入口及详情均提供相对版本链接，共用 `XiaoyaSite.createShell`、全站档案、目录、底栏和同步面板。

原版的248项、四领域、九阶段与技能依赖图保持独立；标准版采用原文五能区（大运动、精细动作、适应能力、语言、社会行为）、28月龄组、261编号项目。表 A.1 和表 B.1 按原编号关联，保留原文名称差异、R/*标记及PDF页码。虽然标准标题为0～6岁，原表含78和84月龄组，浏览保留全部分组；正式适用范围仍为未满7周岁。能力脉络保留同能区标准月龄。根据2026-11-03最新反馈，允许逐项比较附录B动作与条件，添加逐边保留依据的本站整理关系；交互、卡片和箭头语义复用毛老师版；不得将其宣称为原标准规定的必过依赖，不将两个版本的年龄组或项目强行对齐。

毛老师版技能全景在宽窄屏均保留全目录的累计完成数、总数及百分比，与当前追踪和领域筛选分开统计。“定位技能”旁的清除图标清空技能追踪和分支筛选，回到当前领域全景；不自动重新选中默认技能，刷新保持清除状态，之后仍可选择具体技能追踪。此操作只改变阅读状态，不修改完成记录。

卫健委版沿用“宝宝视角／能力脉络／下一步”三种阅读方式。阶段区间为0–3、4–6、7–9、10–12、13–18、19–24、25–30、31–36、37–48、49–60、61–72、73–84个月，仅组织阅读；原有单月龄深链接仍落入对应区间，详情保留原始标准月龄。宝宝视角按阶段、能区、可收起清单及完整脉络组织；能力脉络使用局部滚动画布，定位所选阶段或高亮项目，支持直接记录和打开详情。下一步以共享档案算出的实际当前阶段为参考，不受预览月龄或深链接中的month影响：保留实际当前及此前未观察项目；每个能区单独按最新已观察月龄继续其后首个未观察月龄组，并保留进度以内的遗漏项，不等待同组全部观察完。尚无观察的能区只展示当前及此前项目，不自动开放未来。完成后推进，撤回后重新计算；搜索候选仅检索推荐集合，完整展示当前筛选的全部推荐项，不按数量截断、能区不折叠；与毛老师版相同，依次展示当前、此前、下一及更后阶段。这是原标准缺少逐项依赖关系时的月龄阅读顺序，不套用毛老师版的技能前置图，不将空白记录解释为能力不足，也不套用正式施测起止规则。详情提供同能区按标准月龄排列的上一项、下一项。

卫健委内容来源存于 `data/health-standard.json`，原件为 `assets/wst580-2017.pdf`，可用 `scripts/import-health-standard.py <原件路径>` 再次提取。脚本检查编号、月龄、能区分组及附录B方法的完整性，保留原件SHA-256；表格长标题须按视觉边界检查，不能仅信任默认单元格文字提取。

卫健委宝宝视角图谱保留当前能区全部月龄的项目，默认定位所选阶段或追踪技能，允许左右浏览前后阶段。独立项目不因缺少已确认进阶关系而被裁掉；阶段高亮与关系高亮分别计算，只有显式核对过的关系画箭头，浏览范围扩大不改变记录或下一步推荐。

两版清单的筛选与搜索保持同行，`lib/growth-search.mjs` 按工具栏实际可用宽度收拢搜索：不足以放下筛选与输入框时只显示放大镜，点击打开原生搜索气泡。两版复用原输入框与实时候选列表，关键词只过滤输入框下方的候选，不替换正文或隐藏脉络图；候选保留技能名和月龄，选择后进入该技能单项脉络并定位。卫健委按当前能区与状态检索全部月龄，下一步仍限推荐集合；毛老师版保留当前阶段及领域范围。支持方向键、回车、Escape、无匹配与清空，中文组词结束后更新候选。保留连续输入、清除、重绘及宽窄屏切换时的关键词与焦点；支持外部点击、Escape关闭并返回搜索入口，收起时标明仍有有效关键词。按用户最新要求，辅助搜索输入框统一为32px高、13px字号，收拢放大镜为32px、图标16px，两版共用；其他表单字号不变。

宝宝视角阶段导航右箭头后提供所选阶段的“全部完成”，能力脉络则放在所选阶段的画布标题旁，每个视图只放一个入口。范围固定为该阅读区间内五能区全部项目，与当前能区、观察状态筛选无关；搜索候选与下一步不提供此操作。批量写入复用本版持久保存和同步通知，状态为已观察到，新增观察使用当天日期，保留原已观察项目日期及所有手记，不影响其他阶段。全部观察到后禁用，单项仍可撤回，下一步据此推进。宝宝视角各能区清单标题旁另设独立图标式“全部完成”，范围固定为所选阶段、所选能区的全部项目，状态筛选不缩小范围；保留已有观察日期和所有手记，不影响其他能区或阶段。操作不切换清单展开状态，完成后禁用，撤回单项可恢复。

标准版用于日常浏览和家庭观察，记录“已观察到／暂未观察到／未记录”、日期与手记；正式测查通过条件原文可查，不以家庭观察代替专业施测，不自动计算智龄、DQ或诊断。标准使用说明保留资质、工具、月龄、起止程序和计分规则，并链接原件。入口为“卫健委版”版本标签内的小号圆圈问号，不占侧栏或底部导航；说明可以叠在项目详情上，关闭恢复焦点及未保存观察，保持项目深链接。

本机使用独立 IndexedDB `xiaoya-health/documents/default`，同步area为 `health`，私有仓固定 `records/health.json`；snapshot为 `{version:1,standard:'WS/T 580—2017',records:{'wst580-001':{status,observedAt,note}}}`。两版互不转换、覆盖或推断完成状态。新增数据文件使旧客户端仍可处理原growth文件；同步后端须先更新health接口，再发布新版网页。备份只覆盖本版，导入先校验、预览和显式处理差异。

页面级普通版本导航与详情对应入口分开：页面仍可切换版本首页，详情只显示有人工核对依据的相关项目，不用首页链接冒充对应项。`shared/growth-references.js` 保存双方稳定 ID、原名称、标准月龄/能区、关系类型及差异理由，`shared/growth-versions.js` 共用同一集合提供双向、一对多入口，不取首个候选替代完整关联。现已收录199个标准项目与117个毛版技能之间的222条关系：83条同类动作、139条部分相关；60个未找到对应及2个待核对标准项目不提供对应跳转。毛老师原图缺少逐项完整量化通过要求，因此“同类动作”也未确认测查等价，目前没有证据充分的“完全一致”关系；不根据同名或年龄自动配对。详情按需展开全部关联并逐项说明差异，目标深链接打开详情，毛老师版同时定位并高亮图谱。参考关系不转换完成状态或观察记录，标准说明问号独立保留。

两版普通版本导航共用分类工具栏，位于窄屏目录按钮右侧，正文不再重复版本页签。卫健委说明问号以16px次要图标收进卫健委版本标签内部，与标签共用选中底色，链接与说明按钮保留独立键盘操作；420px及以下可简写为“毛老师／卫健委”，链接无障碍名称仍保留完整版本名。卫健委正文容器不超过600px时，状态筛选与搜索同排，搜索按最新要求使用13px输入字号、32px高度并保留清除入口；以上调整只影响阅读布局，不改变记录、筛选范围或详情对应关系。

成长两版与英语共用小芽全站栏最右侧的“设置”齿轮图标入口，“宝宝资料”、同步、保存状态及备份等辅助操作收纳其中；菜单内容依当前分类及成长版本提供，沿用各自记录与备份范围，不混合记录库。成长两版与英语的“宝宝资料”入口统一使用 `aria-label="编辑宝宝资料"`，复用全站共享档案及各页既有编辑弹窗，保留目录现有入口；均复用共享框架的 `createActionMenu`，使用原生自动弹出层承载原按钮，完整标签与实时保存状态在菜单中显示；支持外部点击、Escape收起及键盘焦点返回，选择操作先收起菜单再打开原有弹层。目录、版本导航及分类搜索保留在下方分类栏。本批入口调整已获用户发布授权，按 main 统一验证与发布流程交付；实际部署状态以 Actions 为准。

原件入口属于各自内容版本，统一位于成长分类栏的版本切换右侧，不进入全站设置菜单。毛老师版“原始图谱”链接 `assets/original.pdf`，卫健委版“原始标准”链接 `assets/wst580-2017.pdf`；保留真实相对链接与新标签打开，窄屏书本图标仍提供完整的版本提示和无障碍名称。卫健委标签问号的标准说明及其中PDF链接不变。

卫健委五能区使用同一蓝色系的独立色阶：大运动为深海军蓝、精细动作为亮蓝、适应能力为天蓝、语言为偏靛蓝、社会行为为雾蓝。进度卡片以深浅底色拉开差异，深底使用白字；清单标题、项目文字、完成圆按钮、脉络和详情沿用对应能区色。选中描边、完成勾选及文字状态同时保留，不只依靠颜色表达操作状态。

卫健委列表状态筛选与毛老师版统一为“全部／探索中／已完成”。未填观察结果、仅写手记及“暂未观察到”共同归入“探索中”，“已观察到”归入“已完成”；详情保留原始观察状态，筛选不改写记录。旧链接的 `status=unrecorded` 与 `status=not-yet` 兼容归到 `exploring`。

毛老师宝宝视角的阶段信息集中在顶部阶段导航，不再在技能清单上方重复显示月龄和当前阶段。全阶段“全部完成”位于导航右箭头之后，作用范围仍为所选阶段四领域全部技能，保留已有日期与手记；420px及以下使用带完整无障碍名称与提示的图标按钮，阶段选择器保留16px表单字号及完整当前选项。

## 一个网站，多个分类

小芽是全科启蒙与成长陪伴网站。成长技能树、英语启蒙是平级分类，而不是两个独立网站。全站首页用于选择分类，分类内部完成具体阅读与记录。

| 层次 | 负责 | 不承担 |
| --- | --- | --- |
| 站点框架 | 分类注册、首页入口、全局切换、局部导航容器、移动目录、快捷栏、焦点与基础阅读样式 | 月龄定位、路线等价判断、技能进阶、素材推荐、记录保存 |
| 分类接入层 | 当前标题、目录项、选中状态、内容节点、业务动作、主题 ID | 复制框架的 DOM、断点与事件处理 |
| 领域内容 | 成长图谱与技能记录；英语路线、素材、儿歌及资料出处 | 修改其他分类的数据或接管站点导航 |

框架采用轻量静态多页面方式，不更换既有领域模型，不引入必须在线请求的导航配置。所有分类共同使用一份导航实现和一套布局变量。

## 分类与路径

| 分类 ID | 标题 | 保留入口 | 主题 |
| --- | --- | --- | --- |
| `home` | 小芽首页 | `home.html` | 中性色 |
| `growth` | 成长技能树 | `index.html` | 成长主题 |
| `english` | 英语启蒙 | `english/index.html#routes` | 英语主题 |

唯一注册表放在 `shared/site-sections.json`。每项含稳定 ID、标题、相对站点根的入口、主题 ID、图标 ID、简介。首页卡片与所有分类切换入口读取同一注册表。新增分类不提供空白占位入口；待内容可访问时再注册。

所有内部导航生成相对路径，显式传入当前页面到站点根的路径。根入口为 `./`，英语为 `../`，单文件导出为 `../../`。不能通过猜测域名、路径长度或 GitHub 账户定位根目录。

注册新分类时还需实现该分类内容入口并接入框架、更新构建清单和主题、完成两旧分类互跳及移动端验收。注册表统一解决导航扩展，不替代业务内容开发。

## 共用交互

导航明确分为两层：全站栏在上，分类容器在下。浅黄色全站栏承载“小芽首页”、全站宝宝年龄和分类链接，最右侧统一放置“设置”齿轮图标入口，所有分类使用同一外观，长页滚动时保持可达；同步、保存状态及备份等通过该菜单访问，内容依当前分类或成长版本的记录范围提供。下方分类容器包含分类工具栏、目录和正文；分类工具栏显示当前分类、页面位置、目录、版本切换及分类搜索。首页不显示分类工具栏。

桌面侧栏和窄屏目录只列当前分类的内容。全站栏与紧凑分类工具栏均随滚动保持可见，目录入口始终可达；手机顶部两栏各为50px，桌面侧栏从两栏下方开始。详情与预览中的分类切换继续提供全站入口。

不超过 `900px` 时，分类目录使用从底部向上展开的全宽面板，替代左侧抽屉。面板随内容确定高度，最高 `85dvh`，上方保留遮罩关闭区域；标题和关闭按钮不随目录内容滚动，长目录在面板内部滚动，底部预留安全区。长名称允许换行，入场动画尊重减少动态效果偏好；超过断点自动关闭并恢复常驻侧栏。该行为由共享样式统一提供，分类选择器仍使用居中弹层。

窄屏底部快捷栏只提供当前分类最常用的三至五项；成长与英语可传入不同项，但使用同一组件和选中规则。完整目录、路线子项和阶段列表留在目录中，不要求所有分类拥有同样的业务名称或数量。

详情和预览的标题栏同样放置共享分类切换按钮。分类选择器可在当前弹层之上打开；取消后恢复原详情、输入值和焦点，不能为打开导航而销毁表单。选择另一分类后使用正常链接离开，沿用现有保存保护。

英语原图预览使用独立的标题栏、工具栏与可滚动画布。关闭入口位于标题栏，工具栏使用与共享浅色主题一致的深色文字和按钮；单页隐藏翻页控件。缩放和翻页重绘保留操作焦点，Tab约束在预览内，底层正文与详情设为inert；关闭按钮、Escape与图片外空白均可关闭，随后恢复来源入口焦点及原有详情滚动锁。图片独立缩放和双向滚动，不参与标题栏尺寸计算。

素材详情“封面与图片出处”的图片也复用上述预览，点击图片或聚焦后按Enter打开；单张素材图隐藏页码，关闭后保留详情滚动位置并恢复图片按钮焦点。2026-11-04本地已验证220视觉词的点击、缩放、三种关闭方式和键盘入口，并回归多页原文翻页；七档代表宽度无整页横向溢出且关闭入口可见。仅本地实现，未发布。

目录与分类选择使用原生 `dialog` 管理模态和焦点。一个时刻仅有一个框架导航弹层；可以位于领域详情弹层之上。所有关闭路径统一清理滚动锁、监听器与 `aria-expanded`。不把框架目录复用为业务表单容器。

## 主题与阅读规则

框架统一字体、字号、间距、容器、断点、圆角、层级、触控和安全区。分类通过 `data-site-section` 和主题变量覆盖强调色、浅底、边框及图标色；颜色之外保留文字、图标或线型表达状态。

导航使用 `900px` 单一断点，图表自行决定显示方式。窄屏不是桌面内容改成一列：先呈现当前任务、当前阶段与摘要，完整证据、套系和参考资料按需展开。保留“查看完整内容”的路径，折叠摘要须说明里面是什么。

模块动作采用紧凑图标工具栏，保留可理解的无障碍名称、悬停提示及键盘焦点，避免把操作拆成多行文字。图谱的缩放、一屏看全、定位当前技能与放大画布集中到画布上方唯一的工具栏，阶段标题旁不再放置重复或近似入口；技能全景中的回到宝宝当前月龄也在此工具栏，以日历图标区别于当前技能定位。缩放和视图操作分别成组，窄屏空间不足时整组换行，不将单个按钮孤立到另一行。图例只解释颜色与连线，不放定位操作；技能清单默认折叠，可点击领域标题展开或收起，普通重绘和宽度切换按阶段与领域保留展开状态。单领域清单占满容器，内部按实际可用宽度自动排成紧凑多列；技能项以 144px 为最小阅读宽度，宽正文改为至少 180px，极窄容器退回单列，不固定占满一整行。技能名称与脉络入口相邻，分类辅助文字另起一行；窄屏或正文容器不超过 700px 时，脉络入口只显示图标并保留完整无障碍名称和提示。名称本身打开详情，不再增加重复的详情箭头；长名称完整换行，完成圆按钮保持 18×18px。

阅读密度按任务与可用宽度调整，不能把手机、平板和桌面统一平铺。手机合并短筛选控件、缩减重复标题和卡片套卡片的留白；平板复用横向空间并排显示短内容，桌面保留完整阅读结构。验收同时记录首个主要内容的位置和交互可达性，横向溢出为零只是基本条件。压缩边距和装饰，正文与触控尺寸保持可读、可点。

正文宽度由内容容器决定，Flex/Grid 子项允许收缩；长中英文名称、标签和按钮允许换行。普通筛选组换行或重排，不能把最后几个选项藏在横滑区域。阶段原生选择器保留完整选项，并在窄屏旁显式显示当前完整阶段名。极窄屏的详情事实栏和套系用法改为单列；成长“下一步”沿用宝宝视角的四领域单排筛选，隐藏装饰图标，保留领域与可探索数量；不足最小阅读宽度时仅筛选区局部横滑。四领域进度卡与明确的图谱、原图仍沿用各自的单排/局部画布规则。进度卡始终保留名称、完成数量、百分比及进度条；正文容器不超过 640px 时隐藏装饰图标，数量与百分比并排，不超过 400px 时百分比另起一行，避免 100% 和完成数量相互挤压。验收必须展开关联阶段和套系表，检查内部 `scrollWidth`、标题及操作的可读性，不能以全局裁剪消除表面溢出。

按用户要求，英语素材标签保持紧凑的内容高度，窄屏上下内边距4px、行高1.5，不设置44px最小高度；起点与关联路线沿用同一密度规则，现有字号不缩小。长名称按需换行，同排短标签不随多行标签拉伸。

成长“下一步”复用宝宝视角技能行与完成、详情、脉络交互；按正文容器宽度紧凑分列，每项保留技能名、分类与月龄。解释、观察、陪玩和手记在名称打开的详情中完整访问，不在推荐列表重复铺开；窄正文隐藏顶部解释，当前月龄合并进阶段图例，资料编辑通过全站设置菜单或统一目录访问。下一步正文达到600px时采用至少260px的连续技能网格，月龄组不再强制独占一行；每项直接注明阶段，不只靠颜色区分。较窄容器保留阶段分组和紧凑多列。完成后推进与撤销逻辑保持原模型。

成长宝宝页不再让完整脉络的说明、追踪摘要阻挡技能：窄屏先显示阶段、四领域进度与技能清单，再直接展示阶段图谱，不再提供重复的“阶段图谱与完整脉络”外层折叠标题；变宽后将原节点恢复到图谱区。按用户要求移除重复的编号路线列表，宝宝视角与技能全景均通过图谱直接追踪关系，按用户要求移除图下重复的当前技能、直接前序与直接后续卡片；解释、手记、完成与回退保留在图中节点及详情中。

| 场景 | 窄屏阅读方式 |
| --- | --- |
| 宝宝视角 | 当前阶段与主要活动优先；参考说明收纳；资料编辑入口可达 |
| 阶段与路线 | 先看一个阶段；前后切换；其他路线先显示对应摘要，再展开完整资料 |
| 素材图鉴 | 单行紧凑筛选；路线与阶段优先，类型、状态和搜索按图标打开；图例仅在ⓘ气泡显示；分批阅读 |
| 成长技能清单 | 先选阶段与领域；优先看当前任务/状态；不把全部阶段清单堆在首屏 |
| 图谱与关系 | 保留聚焦链路与节点交互；手机图谱可拖动、定位、放大，不重复铺设关系卡片 |
| 详情与原图 | 详情摘要和主要动作优先；长套系、引用折叠；图片独立预览与缩放 |

素材图鉴卡片的路线使用明细在桌面与手机统一默认折叠，保留原有阶段跳转、级别与用途；内部按许密杉、庆爸、香蕉妈妈排序，各路线采用独立details，标题旁＋／－表明展开状态。“仅看多路线共用”旁通过同一位置的＋／－图标切换全部展开／全部收起，作用范围为当前筛选的全部结果及内部路线，含尚未加载项；仅当全部外层及路线均展开时显示－，逐卡或逐路线开合后同步更新。本轮按素材稳定ID及路线ID保存展开状态，筛选、加载更多、重绘及宽度切换不重置；此浏览状态不写入宝宝记录。

图鉴全部筛选合并为单行紧凑工具栏，路线及阶段点开完整选项，多路线共用直接切换，类型与套系状态合入同一筛选图标，搜索通过气泡实时过滤结果；ⓘ气泡承载图例、加粗含义、年龄索引与清除筛选。窄容器收紧至28px入口，不增加操作行或横滑；气泡支持外部点击、Escape、关闭及键盘焦点恢复，完整选项不截断。

英语关系地图在窄屏把关系查看方式与中心素材选择合并为同一行32px高的筛选。关系类型使用短名称，完整名称保留在提示中；中心素材的完整名称仍在下方中心卡可读，选择器保留全部选项和无障碍名称。宽屏沿用关系页签与素材选择；年龄关联和阅读难度参考保持各自内容与筛选逻辑。

图鉴卡片以48×60px小封面、完整名称和引用信息组成左侧摘要，套系状态及详情、歌单、收藏图标放在同一摘要行右侧，不再独占下一行；路线明细只保留收藏右侧的＋／－图标入口，收起时不占独立文字行。图标提供素材名称、展开状态与受控内容关联，单项和顶部批量开合保持同步；个人素材的主题与阶段参考沿用同一交互。省略重复“套系状态”说明及单独文字详情行，选择器保留具体素材的无障碍名称。卡片采用容器查询：窄于380px时右侧操作组内分两行，窄于300px时收紧封面，左侧完整名称仍可换行；网格按实际正文宽度自动分列，并使展开卡片与相邻卡片独立定高。记录、版次、筛选、分批加载和路线展开状态沿用现有模型。

正文至少 `15px`、辅助说明至少 `12px`、输入控件至少 `16px`，主要触控目标通常至少 `44×44px`；按用户明确要求，毛老师版与卫健委版宝宝视角的技能清单名称统一为 `14px`，仅此处例外。按用户最新要求，技能清单与脉络图的完成圆按钮在所有屏幕宽度统一为 `18×18px`、勾选图标 `12px`，不扩大其点击区域；通过压缩行间留白和重复信息提高同屏内容量。在 `320px` 宽度也不能缩小文字或把按钮挤出屏幕。窄屏两层粘性工具栏保持紧凑，固定底栏留出内容与软键盘空间。

## 状态与兼容

英语图鉴的状态标从许密杉、庆爸当前年龄方案的全部阶段记录派生；点击查看各路线、阶段和分级数量、庆爸实际／有效时间，并可回到对应阶段记录。它不再写入套系手动状态，筛选与详情使用同一结果。全部所列范围完成才显示已完成；任一范围有数量或时间即为进行中，只有版本或备注仍为未开始。不同路线不累加册数，父子沿用max汇总，不把状态当晋级或必读全套要求。未纳入两条进度路线的素材用独立`library.progress.v1:<resourceId>`记录，保留每个版本范围的完成数量；总数来自已核实出版范围或用户自己的明确填写，未知总数不算百分比。新数量键沿用英语既有status/note同步与备份契约，不覆盖套系原手记或个人素材资料。跨标签／同步更新即时刷新状态和只读明细，正在编辑的表单保留草稿并在保存前检测并发修改。此项为本地实现，发布状态另行核验。

框架仅管理导航开关、焦点与布局模式等临时状态。筛选、当前阶段、图谱焦点、阅读展开和领域记录各由所属分类维护；宝宝昵称和生日使用独立的共享数据服务，导航框架不拥有档案。

成长保留 IndexedDB `xiaoya-growth`、旧记录 `xiaoya-growth-v1` 及查看偏好 `xiaoya-growth-view-v1`；英语保留 `little-leaf-english-v1`。词汇、手记和收藏不得成为公开默认值或框架配置。生日仅按本轮用户明确授权固定，通用成长模型 `DEFAULT_PROFILE` 与英语启动占位仍为空；实际活动档案统一由共享服务初始化。

宝宝昵称与生日统一由 `shared/baby-profile.js` 读写 IndexedDB `xiaoya-site` 的 `profile/default`。根页面、英语及单文件构建使用同一份服务，新增分类直接接入。按用户明确要求，个人自用网站的生日固定为 `2024-11-24`；自动沿用该生日的旧档案，无匹配资料时以该生日建立档案，不再弹出选择框。已有共享资料若生日不同也按此规则归一。迁移来源保留，领域记录不删除。昵称仍可全站同步修改，生日只读。

成长数据库和 JSON 备份仍包含基础档案的兼容快照，活动页面以共享档案为准；英语本地 profile 仅写词汇量、呈现偏好等专属字段，导出时附上共享姓名与生日。跨标签使用 BroadcastChannel 通知，并在页面重新可见时回读；旧表单检查打开后的并发修改，冲突不覆盖。同一浏览器、同一网站来源内共用；本地预览、GitHub Pages 和 file 页面不属于同一来源，这不代表跨设备云同步。

继续支持既有根地址、英语 hash、浏览器后退、单文件导出和 JSON 备份。不得用替换根入口、改存储来源或新增强制登录来完成框架统一。

## 构建与维护

共享文件为 `shared/site-sections.json`、`shared/site-shell.js` 、`shared/site-config.js`、`shared/site-home.js` 和 `site.css`。根页面与首页载入共享运行时，英语构建将同一份注册表、运行时和样式内联，以保留离线单文件能力。生成 HTML 不作为独立维护源。

统一构建走 `scripts/build-site.mjs`，输出 `dist/site`。运行时文件按白名单进入发布包；`AGENTS.md`、本文件、方案和测试保存在 `main`，不复制到公开网站包。GitHub Actions 从已合并的 main 上传并部署 Pages 产物；`codex/pages` 仅保留旧发布历史，开发会话不再各自操作发布副本。

英语与成长是同仓库的两个独立开发 worktree 和会话，分别读取本工作区 `xiaoya.area=english/growth` 并使用 `codex/english/<任务>`、`codex/growth/<任务>` 分支。日常修改与验收完成后保留在本地，同一批需求可累计迭代；只有用户明确要求“提交合并”或等效指令后，才统一提交并推送。分支推送后自动创建面向 main 的 PR，main 要求最新基线和 verify 检查，使用 squash 自动合并。主分支推进时，协调器更新其他开放任务分支并重新验收；有冲突则保留 PR 等待处理。共享框架改动在任务分支同时验收两分类，隔离工作目录不代表拆分产品框架。

`.github/workflows/auto-pr.yml` 仅从 main 读取协调代码，负责创建 PR、同步基线和安排合并。验证工作流 `.github/workflows/site.yml` 对 main、两类专属分支的 push 或显式 dispatch 运行测试与完整构建，只有 main 可以部署网站。机器人 PR 不另外触发 pull_request 检查，避免人工授权造成流程停滞。内置 GITHUB_TOKEN 的后续事件不会可靠派生，因此协调器显式 dispatch 验证，直接等待本次同一提交的结果，再安排受保护合并、main 发布及其他开放任务分支的基线同步；不依赖个人 Token。成功验证必须与 PR 当前 head SHA 相同，过期运行、失败检查和外部 fork 不参与自动合并。等待验证超过十分钟时保留 PR，可重跑原协调工作流。

每次框架修改同时验收成长、英语、首页、详情与预览，覆盖窄屏、断点两侧和宽屏；保留状态与未保存行为。方案、实现状态和验收证据分开记录，不用设计目标充当通过证据。
