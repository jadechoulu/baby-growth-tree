# 英语主题与场景两级分类

本规范适用于素材图鉴、Hello 和 SSS。一级主题／场景共用，二级按内容细分；原资料中的场景、童谣主题、歌单名称、来源及难度分别保留。本站分类用于查找材料，不表示作者路线、年龄、难度、主辅线、必读要求或个人完成状态。

## 主题、活动方式与难度

- **主题／场景**回答内容讲什么、适合在哪个场景使用。一个条目允许多个有依据的主题，例如数鸭子可同时关联动物和数量；穿衣可同时关联生活流程与衣物。
- **TPR**是听指令做动作的活动方式，独立于主题。刷牙也可使用TPR；出现动作词不代表该材料已经采用TPR。只对有实际活动依据的条目标注，不由“动作”主题自动生成。
- **难度**保留具体整理者、版本及原始等级，不参与主题父子关系。不同资料的Level不能直接换算，更不能描述成SSS官方统一等级。
- **童谣、经典、歌单**属于内容形式或整理集合，不作知识主题。主辅线、选材要求、路线阶段及个人记录继续遵守[素材标签与图例规范](material-tags.md)。

## 原始标签与证据边界

Hello的`parts[].scene`及童谣`themes/themeSource`继续保存原文。“刷牙”“日托”“雨天玩水”等原名称仍可搜索、显示及按原场景查找，通过公共映射关联统一一级和二级，不为统一外观改写原资料。场景归属只作用于该Part；童谣只采用本首主题及已核实对应Part，不能因同册其他Part命中而把主题扩散整册。

书目保留既有主题证据、来源、版次及稳定ID。旧分类宽于新二级时，只关联能确认的一级；“身体与健康”“朋友与情绪”等旧宽泛分类不能机械换成一个更窄的新二级。按用户2026-11-14最新要求，补全时先检索小红书等具体资料，再采用本册正文／公开内容简介，最后允许按明确题名兜底。题名兜底须作为暂定标签单独标示，不能冒充已核正文或借用套系其他册的内容。运行时不根据新输入的题名猜分类，只读取离线生成、可复核的稳定ID映射。

SSS逐曲映射结合已读歌词、官网分类和资料中的字词句说明；整理表存在不同分类时，记录来源与适用范围，不把表内分组当作内容定论。例如100首表将《Say Cheese》放入食物，但同表说明为拍照与表情，不能仅因cheese一词归食物。不同歌曲版本继续使用原ID和官方链接，不按同名合并个人记录。

新增或调整映射时记录原标签、采用节点、具体依据和来源。主题整理不迁移收藏、完成、日期、手记、选版及同步记录键，也不改变路线引用或素材数量。

## 共用模型与交互

| 职责 | 公共入口 |
| --- | --- |
| 分类节点、父子关系、来源及显式映射 | `english/data/topic-taxonomy.json` |
| 一级与二级选项 | `EnglishTopics.roots()`、`children()`、`options()` |
| 共用筛选器、主题标签、图例与按需证据 | `english/topic-ui.js`的`picker()`、`tags()`、`legend()`、`evidence()` |
| 统一节点名称 | `node()`、`label()`、`labels()` |
| 按领域原始条目取得公共主题 | `entryTopics()`；书目、Hello Part、Hello童谣及SSS歌曲分别处理 |
| 父级展开与筛选判断 | `expand()`、`matches()` |
| 普通、单文件及发布构建 | `english/build.py`加载同一数据、`english/topics.js`及`english/topic-ui.js` |

先选择一级，再可选该一级下的二级。只选一级时包含其全部已归类二级以及仅能确认到一级的条目；选二级时必须精确命中，不能把一级宽泛映射当作命中全部子级。切换一级后清除不属于新一级的二级。路线、阶段、书号、曲调、关键词及个人收藏等条件与主题取交集，不因改主题自动重置其他条件。

图鉴、Hello与SSS调用同一模型，不各自手写映射、父子筛选或别名表。筛选入口保持紧凑、名称完整、键盘可用；关闭、Escape及焦点恢复沿用各页现有机制。图鉴主题弹层仅保留一级、二级选择器，不放“查看全部单本”、分类说明或书目核对范围；选择具体主题显示匹配单本，恢复“全部主题”返回套系浏览并保留列表／封面布局。标签是说明，只有明确筛选或导航操作使用按钮。普通重绘、视图切换及宽窄屏变化保留本轮选择，临时主题筛选不写入宝宝记录。

## 维护与验收

分类变更须同时核对公共模型、图鉴、Hello和SSS；至少验证一级包含子级、二级精确匹配、跨条件交集、切换一级清理不兼容二级、原场景与主题可查、空结果及清除恢复。Hello还需验证Part与童谣的边界，不能用整册聚合代替逐条判断。构建须覆盖普通入口、单文件和站点包；交互和既定宽窄屏验收另记具体结果。

本规范记录长期分类与维护约定。2026-11-05本轮接入属于本地工作，不代表已经提交、发布或完成全部内容证据核查；实际实现与验收状态见[架构文档](architecture.md)及本轮交付记录。


## 逐册原表与系列内筛选

RAZ AA、A与培生基础词汇的原件保存在`english/assets/sources/reading-guides/`；元信息、原表书号、工作表位置、原始主题顺序与句型由`scripts/import-reading-guides.py`并入公共`resource-books.json`，不在页面列出具体单词。原件下载仍保留完整内容。逐书公共映射在`reading-guide-map.json`维护；旧目录的补证在`book-subtopic-supplements.json`保存，构建前导入到同一个`topic-taxonomy.json.bookOverrides`，不建立页面专属主题库。

表格分组并非自动正确：结合本条字词句核对内容，内容主题不从词性或故事角色推定；按用户2026-11-14要求，句型另作为一级检索维度，与内容主题并存。原表题名冲突留在来源`unmatched`，不按同号绑定另一书的进度。只支持一级的条目保留一级；旧版与新版同名不能借用二级，待核理由保存在`subtopicPending`。新增节点与逐项纠正依据见[本批审计](audits/reading-guide-topic-review.json)。

系列内统一调用`seriesTopicBrowser()`与`EnglishLibraryBooks.seriesFilter()`，版本、一级、二级取交集，一级包含子级；清回“全部主题”恢复全目录。分页、返回单册、普通重绘保留本轮筛选，筛选只改变展示，不改变完整版本的进度分母、稳定书目ID或个人勾选。图鉴主题筛选读取同一逐册映射。

主题筛选后的图鉴结果在筛选栏下增加一行套系Tab。`EnglishLibraryBooks.seriesGroup/seriesGroups`读取公共书目的`resourceId/seriesTitle`和来源明确的`level`归组，培生上下辑同组、RAZ AA／A分组；不按分辑册号拆套系，也不单写RAZ判断。选项本数取当前主题、路线、阶段、搜索和状态的完整交集，不受分页或当前套系选择影响。套系选择再取交集，失效时恢复全部；清除主题隐藏并清空此行。Tab支持左右方向键、Home／End及局部单行横滑，布局切换、分页、详情返回保留选择与本轮横滑位置，不进入私人记录。

## 主题路径、阶段范围与句型检索

图鉴选主题后，筛选栏下常显“一级主题／二级主题”，仅选一级时二级写“全部”。类型、状态默认选项简称“类型”“状态”；同一筛选栏提供“重置”，清除路线、阶段及范围、主题与二级、套系、类型、状态、关键词和多路线共用条件。阶段范围默认“只看当前阶段”，选阶段后可切“包含更低阶段”；公共`EnglishModel.libraryStageIds()`只沿同一路线执行主表或同一来源版本向前取，不跨作者、领域或其他版本借序号。筛选不改变个人进度或完整目录分母。

结果由`EnglishModel.sortLibraryMaterials()`按有据路线阶段从易到难；同阶段按类型、用途、同套明确级别稳定排列，不从题名或册号猜难度。套系Tab调用同一函数的`typeFirst`模式，先分级、绘本、动画，再儿歌、闪卡及其他；每类内部沿同一难度依据。未核定难度放后，不宣称跨出版社级别等值。

“句型”是第21个一级检索维度，二级直接采用已维护的`studyGuide.patterns`及经`withReadingPlans()`投影的阅读计划句型；`patternMappings`按来源ID和规范化的原句型精确映射，不按书名或关键词生成。仅合并省略号、空白、大小写与弯引号差异，保留a／the及人称等结构区别。句型原文继续在逐册书单独立一列展示，不混排为内容主题。原表疑似错字保留差异、暂不创建检索节点。

2026-11-14核对用户指定两篇小红书配图。启明星按同版题名逐册对应，表中故事线、童谣形式、挑战难度和混合分类不能强拆内容二级；Role／Plays按用户确认映射“运动与游戏／角色扮演／小剧场”。基础词汇笔记中部分题名、词汇、句型列疑似错位，继续采用已存的用户原表与既有95册有据映射，不按笔记序号重绑。逐项出处及未采纳原因保存在[培生主题核对记录](audits/pearson-topics-20261114.json)。

## 全素材补全与证据分层

素材范围包括公共单册、路线套系、动画、歌曲、闪卡、教材与廖彩杏作品，不只覆盖已有逐册目录的分级。小红书检索日志区分已检索、实际读到正文／配图、空结果、限流及未检索；搜索结果标题不能冒充已阅读全文，限流不能记成“没有分类”。

- 已有正文或分类表核对保持`content-verified`／`classification-verified`。新补简介归类用`description-derived`，保存本册公开简介摘录、来源URL、匹配词和离线规则；整套宣传文、系列名、模板化阅读级别介绍不得扩散成每册主题。
- 标题兜底用`title-fallback`，保存完整题名、匹配词和理由，页面标示“书名兜底”／“标题兜底”。明确的动物、天气、生活场景等可归类；品牌、角色名和含糊题名仍可待补，不把皮特猫当宠物教学、蓝色小考拉当颜色教学。后续找到更强内容依据时替换兜底，不能覆盖已核分类。已有一级而缺二级时，允许在同一父级内据明确题名补二级，或据本册简介补细分；二级的`subtopicStatus/subtopicBasis`单独保留，不能把原一级已核状态降级或借标题跨维度扩散。
- 句型必须有实际表格或原文，主题的标题兜底许可不扩展到句型。读者整理、亲子拓展与逐字原句分别说明；“动词开头”“制作帽子的步骤”不作为具体句型。只对应已核套系、级别与题名，不因同名跨版绑定；不能确认版次的转录保留为参考。
- 系列主题只表示系列可涉及的范围；不下传到全部单册／每集。`resourceMappings`维护资源范围，`bookOverrides`维护具体单册，Hello／SSS仍遵守原Part与逐曲边界。筛选聚合调用`EnglishLibraryBooks.materialEntries()`；已有单册目录的套系不重复混入整套卡，未建逐册目录的素材复用原详情与完成记录。

离线配置为`material-book-topics.json`、`material-resource-topics.json`与`material-topic-research.json`；`scripts/import-material-topics.py`将它们并入现有公共`resource-books.json`与`topic-taxonomy.json`。`scripts/classify-material-topics.py`负责可复现的简介／标题候选生成；不在浏览器加载原始简介或本机采集路径。`EnglishTopics.patterns()`统一组合原表和补充句型，图鉴与进度书单独立展示句型，具体来源在“主题依据”按需展开。

补分类不能更改稳定ID、外站匹配、版本范围、路线阶段、出版数量、完整目录分母或个人完成事实。验收同时保护主题交集、全部媒介检索、来源级别、原表优先及混合结果详情入口；新增简介证据继续按单册分片，不增加内容首次显示的等待链。
