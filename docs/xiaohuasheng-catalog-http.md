## 默认方式与图片规则

优先使用直接 HTTP 请求，解析服务器返回的 HTML 或 JSON 内的 HTML 片段，无须启动浏览器或执行页面 JavaScript。目前未验证完全不含 HTML 的全量结构化图书接口。

**封面、图片只保存小花生提供的原始 URL 元数据，保留查询参数，不下载图片、不复制进项目静态资源、不上传到自己的存储。** 源站链接失效时重新查询 URL 或显示缺图，不自动镜像；需核对题名、级别与版次，不能用套装图冒充单册。此规则用于后续采集，不批量改写既有素材、稳定ID或个人记录。

每条书目保留 URL 中的`book_id`、原题名、详情URL、封面URL、来源URL、所属系列及采集时间；有依据时补ISBN、出版社、级别和版本，缺失字段留空。`book_id`与详情中的数字`hidBookId`不是同一标识，不得互换。

## 获取路径

### 搜索

```bash
curl --fail-with-body --silent --show-error --connect-timeout 10 --max-time 35 \
  'https://www.xiaohuasheng.cn/Home/SearchBookLoadMore' \
  --data-urlencode 'content=raz' --data 'offset=0&limit=20'
```

- 使用表单`content`、`offset`、`limit`，下一批按`offset += 本批返回数`推进，不能按去重后的数量推进。
- 响应头实测为`text/html`，但正文可JSON解析为`[列表HTML片段, 本批数量字符串]`；校验数组、片段及非负整数数量，再解析片段中的书目，核对解析条数与返回数。
- 本批数量不是总量。满页继续，合法短页／空页仅作候选终点；超时、空响应、HTTP错误、错误页或解析失败均不等于空书单。
- 搜索同时包含系列集合与单册，需通过详情及所属系列识别。关键词结果不能证明出版方全部版本／级别已覆盖；`/search/all/`空结果也不能代替图书搜索结论。
- 交接中成功匿名请求未携带Cookie、Token、签名或`time`；这仅说明当次公开接口可用，不保证后续访问规则不变。ISBN精确查询尚未实测。

### 系列与单书详情

```text
GET https://www.xiaohuasheng.cn/series/{series_id}
GET https://www.xiaohuasheng.cn/book/{book_id}
```

先通过搜索定位候选，再由单书详情核对系列、级别与版本，沿系列响应内**实际发现的分页链接**遍历，不靠无限猜页码判断结束。单书详情补充出版社、页数、词汇量等实际字段；列表缺失的信息不能编造。

`POST /Read/autoSearchBook`（表单`q`、`limit`）仅作联想候选补充；交接请求20项只返回10项，未验证其分页，不用于全系列枚举。

## 分页、身份与完整性

- 站内按`book_id`去重；跨版本结合ISBN、出版社、级别等核定，不能只按标题合并，不能直接用新采集ID替换公共单册稳定ID。
- 保留请求范围、响应状态、每页返回数、成功／失败页、发现／访问页及唯一书目数。有限重试、低并发；401／403／429停止，不把失败当结束。原始响应和中间结果留在本地采集目录，不进入站点发布包。
- 全系列完成须同时核对系列声明册数、唯一`book_id`数和所有发现分页的覆盖；总量变化、页码回退、重复页或缺页均保留未完成状态。达到请求上限不等于完成；即使示例脚本给出完成标志，也须额外核对声明册数。
- HTTP采集可避开浏览器CORS读取限制，但不会继承浏览器登录。代理只作为可选运行参数，不硬编码本机端口或把代理当网站接口要求。
