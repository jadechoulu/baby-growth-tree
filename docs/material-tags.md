# 英语素材标签与图例规范

本规范覆盖路线全景、阶段详情、许密杉／庆爸进度、素材图鉴的列表与封面视图、套系明细。新增页面沿用同一模型与渲染组件。成长能区色、作者身份色保留各自含义，不转作英语素材用途色。

册数统一读取公共套系目录`resource-volumes.json`：版本及每级数量属于素材基础资料，路线只引用`scopeId`，不另存数量。各处调用`EnglishModel.publicationEntry/publicationScopes/publicationLevelScopes`；同版分项去重，嵌套包按`includedIn`排除重复。已核实出版范围与作者实际选版分别表达：未选版可显示“可选版84／96本”，不能据此计算本人百分比；有多级子项时逐级展示，父项不混用另一版本的组合总量。主辅线、共用加粗和状态不受数量补证影响。

图鉴册数弹窗默认展示各版本的完整具名级别／色带组合与册数，如Pink 1A＋1B；组合数从公共分项求和，不另存总数。级别直接展开，版本说明及来源按需展开，不显示逐本目录、封面或已录入书目条数。主题筛选仍使用原逐本书目；逐本覆盖不足不能代替出版级别范围。素材详情及进度页复用同一“各级册数、版本与来源”入口，不另列重复表。指导册、练习册、卡片等与读物分别核算；词卡可明确使用“张”，不能将词数当作读物册数。

素材完整详情只用“路线使用阶段”的作者分组列表展示路线、阶段、级别、册数及ⓘ用法出处，不在上方再平铺同一素材的路线进度；实际个人进度统一由状态标打开，沿用原进度模型。此规则由全部素材共用的`resourceDetail()/seriesProgression()`实现，不按套系特判；卡片、详情与同步更新统一调用`resourceProgress()/resourceStatusControl()`，不另外保存展示状态。出版版本总量仍由册数入口查看，不与路线引用范围混用。

主题／场景采用[英语主题与场景两级分类](topic-taxonomy.md)中的20个共用一级与二级节点。素材图鉴、Hello和SSS共用`english/data/topic-taxonomy.json`及`english/topics.js`，通过`english/topic-ui.js`生成筛选器、标签、图例与按需主题依据，不在视图内重复判定分类。原始场景、逐首主题和证据保留；允许多标签，只映射到证据支持的颗粒度。一级筛选包含子级，二级精确匹配；TPR是独立活动方式，来源难度另存，不表示主题、主辅线或必读要求。

## 含义与视觉

| 维度 | 分类与含义 | 视觉与依据 |
| --- | --- | --- |
| 阶段用途 | 主线、特色推荐、辅线、未标主辅 | 主线蓝色，特色推荐琥珀色，辅线灰绿色，未标主辅中性灰；文字、用途标签、用途背景及单项进度条共用该次引用的颜色变量 |
| 选材要求 | 原文明确的选2–3部、任选2部、挑选、可选等 | 单独的中性虚线短标签，不新增主辅线类别；级别文字已包含同一要求时不重复显示，完整原文仍在ⓘ中列出 |
| 共用套系 | 当前比较范围中多个路线引用同一套系 | 仅套系名称加粗，不表示主线、必读或已完成；图鉴按全部路线，阶段对照按当前同排关联阶段计算 |
| 重叠级别 | 当前比较范围中有实际交集的具体级别 | 仅对应级别片段加粗，其他级别、数量和限定不跟随加粗；不是整阶段等价 |
| 阅读状态 | 未开始、进行中、已完成 | 依据个人真实记录；未开始中性、进行中琥珀、已完成绿色。状态文字始终保留，不以用途色替代状态 |
| 类型、版本、主题、作者 | 素材类型、实际出版版本、内容主题、来源路线 | 独立的说明或筛选维度，不由其推断主辅线、难度对应、选读要求或完成状态；作者色点仅区分作者 |
| 引用数量、册数 | 数字引用图标表示阶段引用次数；册数表示当前筛选范围的读物总量 | 两者不得混用；未知册数不补猜测百分比；引用图标的解释统一在ⓘ中 |

用途归属以“路线＋资料版本＋阶段＋原始引用”为单位。同一套系可有不同用途；无原文依据时统一为“未标主辅”，保留原用途与来源，不把分支、类型或共用程度解释成主辅线。

主线表示主要材料，不能自动解释为每套、每册全部必读。庆爸常规4的Little Fox主线明确“选2–3部”，常规5明确“任选2部”；这些要求与主线角色同时成立。缺少选材说明时不额外生成“选读”“任选”“必读”要求，也不把完成率当作能力晋级条件。

## 逐项用途证据契约

每条用途以“路线＋资料版本＋阶段＋原始引用”为核查单位，显式保存 `roleEvidence`，由公共模型提供给各页面，不在视图中重新推断。同套系、同名素材或同阶段内的其他引用已核定，不代表本次引用已核定；修改证据与展示角色不改原始 `material.role`、来源、级别、稳定ID或个人记录键。

| 字段 | 含义与维护要求 |
| --- | --- |
| `status` | 只用 `confirmed`（已取得足以核定本次用途的明确依据）或 `unresolved`（所列资料已核查，但本次主辅尚未核定）。检查过（checked）、找到书名或读过整表均不等于角色已确认；尚未实际核查不得虚填核查日期或描述为已核查 |
| `kind` | 只用公共分类 `main`、`featured`、`auxiliary`、`reference`，分别对应主线、特色推荐、辅线、未标主辅；尚未核定时保留 `reference` |
| `usage` | 保留该次引用可读的原文用途或栏目，例如“闪卡式绘本”“平行拓展”；它不是新增的全局角色 |
| `basis` | 说明本次核定或暂未核定的理由、适用范围及必要限制，不能仅写“同系列”或“已查过” |
| `checkedAt` | 本次实际核查日期，使用 `YYYY-MM-DD`；不能借用资料发布日期或其他条目的核查日期 |
| `sources` | 逐条保留 `sourceId`、`page`、`quote`、`note`：资料ID、具体页／图位置、可核对原话、范围或关联说明。不能把本站推断写成原话；未取得明确主辅原话时保留所核栏目及未能核定的说明 |

“未标主辅”仅表示本次引用尚未核定，不能写成“作者没有分类”或“作者从未划分”。已核查（checked）与已核定（confirmed）的区别应在来源说明中可查，不能通过填色让已查未定项看似已确认。

许密杉六阶段表与全景图的阶段、词数或级别范围不一致时，禁止整表复制角色。只有核对具体材料、级别范围、原文用途及对应关系后，才可逐条采用跨资料证据，并在 `basis`、`sources[].note` 写清范围和差异；未对应的级别继续待核。原文明确的“平行拓展”统一规范为“辅线”，`usage` 与出处保留原话，但它本身不等于“可选／任选”，不能自动生成选读要求。

## 交互与布局

- 用途、选材、类型等普通标签是说明，不添加按钮外观、悬浮点击手势或无意义Tab焦点。
- 点击素材名称或封面查看详情，点击ⓘ查看图例、选材要求和来源；展开收起使用＋／−，不让普通标签承担多个动作。
- 可操作状态使用真实按钮，保留描边、箭头、完整`aria-label`及键盘焦点；不可操作状态使用文字或标记，不能仿造可点击按钮。路线关联状态只展示派生结果，点击查看各阶段记录，不独立改写状态。
- 历史好价统一收进素材完整详情；卡片不再设置独立好价ⓘ入口，点击封面或标题后按需展开，保留原报价及来源。
- 图鉴卡片默认封面视图；套系及主题筛选后的单册共用当前布局选择，过滤、清除与加载更多不改布局，单册结果也保留布局切换入口。新增素材用＋，全量展开／收起用向外／向内角箭头，避免两个动作使用相同图标。
- 图鉴卡片完整标题在类型属性之前，类型用紧跟标题的图标表示并保留完整名称提示；引用数与状态、收藏、展开统一置于次要操作栏。册数按钮只写数量和单位，版本、范围、完整性及证据在详情中查看，不将目录覆盖冒充完整全集。
- 标签按内容自然换行，不固定增高，不截断长中文或英文名称；说明字号至少12px，正文与表单遵守既有全站规则。
- 路线阶段卡中的素材标签全部展示，阶段对照与独立排列使用同一规则，不按条数截断，不显示“＋N项完整资料”。
- 图例默认通过ⓘ按需展示，各页面调用相同内容；短气泡支持外部点击、Escape关闭及焦点恢复，详情浮窗沿用共享关闭与焦点约束。
- 选材完整要求在阶段ⓘ中列出；材料标签只保留短要求，不为增加说明另占一整行。

## 代码入口

| 职责 | 唯一入口 |
| --- | --- |
| 用途分类与展示名称 | `english/model.js`的`materialRoles`；`getStageMaterials()`统一提供`role.kind / label / usage / basis / selection` |
| 用途依据与选材要求 | `materialRole()`按该次引用判定；选材仅读取原文明确要求，不按分支推断 |
| 逐项用途核查 | 每次原始引用的`roleEvidence`提供状态、核定结果及可追溯来源；已核查不冒充已核定 |
| 名称、级别、共用加粗、选材短标 | `english/material-ui.js`的`create().name()`和`title()` |
| 用途短标与图例 | 同一组件的`roleTag()`和`legend()`；页面不得复制分类表或另写解释 |
| 用途色与标签样式 | `english/styles.css`的`.material-role-*`变量、`.material-role-key`及`.material-selection` |
| 状态与真实记录 | `english/practice.js`的派生数量／状态模型；`english/app.js`的`resourceStatusControl()`共用交互 |
| 两级主题／场景及原标签映射 | `english/data/topic-taxonomy.json`；`english/topics.js`的`roots/children/entryTopics/expand/matches/options` |
| 页面构建 | `english/build.py`加载公共组件，重建普通入口、离线单文件与站点发布包 |

新角色须先补来源及模型定义，再统一更新公共组件、样式、ⓘ和本规范，不能在单个页面添加私有分类。原始`material.role`、级别、来源、稳定素材ID及`unitKey`不因文案或样式改变。修改后验证各路线、两进度页、图鉴两种视图、详情及宽窄屏；源码和生成页都要更新。本规范不代表相关修改已发布。

逐册封面按书名与版次逐本核对并保留来源页和核对日期。不同版次不共用未经确认的图；未取得可用单册图时使用套系图且显式标注，不将套装图描述为单册封面。
