# 英语素材标签与图例规范

册数与进度复查应覆盖全部公共素材和来源／执行阶段，通过`scripts/audit-material-progress.mjs`分别核对逐本入口、数量分母、候选版本及待核范围。明确虚构选本由公共`directoryMatch.bookIds`复用原单册，图鉴关联与进度范围都须排除非成员；不能只加正向关联后又按同级别带入整级。无分母候选不阻挡唯一有效目录；多个有效版本保留用户选择。组合级别使用同版明确分项，不拆摊旧数量，不改个人稳定键。

本规范覆盖路线全景、阶段详情、许密杉／庆爸进度、素材图鉴的列表与封面视图、套系明细。新增页面沿用同一模型与渲染组件。成长能区色、作者身份色保留各自含义，不转作英语素材用途色。

进度页点击素材名称须保留本次引用的级别和范围。已绑定完整目录时打开对应逐本计划；尚未绑定版次／选读子集时，按公共级别解析展示已收录参考书目，支持级别、主题筛选与共用单册勾选，不退回套系首个完整版本。参考目录不补造虚构子集、不绑定作者选版、不改变阶段分母或稳定记录键。

进度行不能把“总量未定”和“可选目录已有总量”都隐藏成空白：已确定范围显示完成／总量；没有既有选版且当前级别只有一个有总量的公共目录时，默认采用它显示完成／总量；多个未选候选显示“可选N本／集”；仅有对应级别参考书目时显示“目录N本”，不作为阶段分母；没有可对应范围则明确“范围待核／总数待核”。原文明确的分集范围进入公共数量目录，不把季数换算为集数。补齐分母不改变既有级别分项键，公共范围可通过`recordByLevel`保留原级别拆分与旧数量回显。

册数统一读取公共套系目录`resource-volumes.json`：版本及每级数量属于素材基础资料，路线只引用`scopeId`，不另存数量。各处调用`EnglishModel.publicationEntry/publicationScopes/publicationLevelScopes`；同版分项去重，嵌套包按`includedIn`排除重复。已核实出版范围与作者实际选版分别表达：未选版可显示“可选版84／96本”，不能据此计算本人百分比；有多级子项时逐级展示，父项不混用另一版本的组合总量。主辅线、共用加粗和状态不受数量补证影响。

图鉴册数弹窗默认展示各版本的完整具名级别／色带组合与册数，如Pink 1A＋1B；组合数从公共分项求和，不另存总数。级别直接展开，列表各宽度至少两列，宽容器按可用空间增加列数，长名称及分辑说明自然换行；版本说明及来源按需展开，不显示逐本目录、封面或已录入书目条数。主题筛选仍使用原逐本书目；逐本覆盖不足不能代替出版级别范围。素材详情及进度页复用同一“各级册数、版本与来源”入口，不另列重复表。指导册、练习册、卡片等与读物分别核算；词卡可明确使用“张”，不能将词数当作读物册数。

素材完整详情只用“路线使用阶段”的作者分组列表展示路线、阶段、级别、册数及ⓘ用法出处，不在上方再平铺同一素材的路线进度；实际个人进度统一由状态标打开，沿用原进度模型。此规则由全部素材共用的`resourceDetail()/seriesProgression()`实现，不按套系特判；卡片、详情与同步更新统一调用`resourceProgress()/resourceStatusControl()`，不另外保存展示状态。出版版本总量仍由册数入口查看，不与路线引用范围混用。

素材已读状态只归公共素材、版次、级别及稳定单册ID，图鉴、详情与路线进度共用；有完整公共目录时，状态入口也通过`readingPlanForResource()`读取同一计划，不仅识别手工编排计划。手工勾选、小花生事实、撤回及同步更新沿同一投影路径回显；路线计时、备注和手工阶段完成仍独立，不据素材已读自动晋级。

同一套系统一名称和素材实体；历史简称及重复素材ID只作搜索、来源与记录兼容，不再成为图鉴或路线中的独立素材。出版版本和有限选集在同一素材下分开维护，不将不同版本的数量、逐册身份或完成记录混算。归并由`resource-volumes.json`的显式`catalogResourceId`提供依据，公共模型统一引用；保留旧`recordResourceId/recordLevel`以回读原阶段记录，单册ID不变。素材名中原本隐含的GK70标尺移入级别，保留其与LLI字母级的区别。

公共单册勾选框以绿色表示手动已读、蓝色表示含小花生同步已读事实；两者同时存在时使用蓝色。不再在书目行右侧单列“小花生已读”文字，来源保留在勾选框提示和无障碍名称中。外部已读的原有只读规则不变，禁用时仍保留来源颜色；素材图鉴与逐本书单共用`bookCompletionControl()`，不新建完成状态或迁移记录。

逐本进度书单保留公共目录已有的单册封面，通过`libraryBookCover()`与图鉴共用图片及缺图处理，按稳定单册ID引用，不另存路线图片。有图时放在完成勾选框与书名之间，窄屏保留缩略图和可换行的完整书名；原表顺序、主题筛选及完成状态不受影响。

逐本书单的原表句型独立放在书名、主题右侧的“句型”列，公共目录读取`studyGuide.patterns`、原始阅读计划读取`patterns`，不重复混排在主题标签中。窄屏列内完整换行；当前范围没有句型资料时不展示空列，不补造句型，不展示具体单词。

同版同级别的已读数量由`EnglishPractice.sharedQuantity/sharedQuantityUpdate`共用，旧阶段键只作同范围回读，重复数量不相加；新共用记录（含0）优先，支持减少或撤回。选读版本由`sharedEditionRecord/sharedEditionUpdate`共用。不同版、级别或整套与分级不互相拆摊；原手记、计时和稳定键保留。许密杉路线与进度共用300／500／800／1000／2000词五节点：300引用原闪卡和闪卡式绘本两阶段，500引用GK A、B两阶段，800引用GK C，1000引用牛津树3–5，2000沿用全景图。原阶段的素材、角色、句长与方法留在节点内部，公共模型按stageGroups生成引用，个人数量、备注、日期及稳定记录键沿用来源阶段，不因归组新建一套进度。

主题／场景采用[英语主题与场景两级分类](topic-taxonomy.md)中的20个共用一级与二级节点。素材图鉴、Hello和SSS共用`english/data/topic-taxonomy.json`及`english/topics.js`，通过`english/topic-ui.js`生成筛选器、标签、图例与按需主题依据，不在视图内重复判定分类。原始场景、逐首主题和证据保留；允许多标签，只映射到证据支持的颗粒度。一级筛选包含子级，二级精确匹配；TPR是独立活动方式，来源难度另存，不表示主题、主辅线或必读要求。

图鉴选定具体阶段或宝宝当前浏览起点后，套系与主题单册标题统一由`EnglishModel.libraryMaterialRole()`读取当前路线、阶段交集内的实际引用，经`materialUI.name()`使用公共用途色；未选阶段保持默认色，多次引用用途冲突时保留中性色并可展开查看。单册只使用自身引用，不借整套或筛选外阶段的用途；共用加粗与个人阅读状态不受影响。

## 含义与视觉

| 维度 | 分类与含义 | 视觉与依据 |
| --- | --- | --- |
| 阶段用途 | 主线、辅线、未标主辅 | 主线蓝色，辅线灰绿色，未标主辅中性灰；文字、用途标签、用途背景及单项进度条共用该次引用的颜色变量 |
| 选材要求 | 原文明确的选2–3部、任选2部、挑选、可选等 | 单独的中性虚线短标签，不新增主辅线类别；级别文字已包含同一要求时不重复显示，完整原文仍在ⓘ中列出 |
| 共用套系 | 当前比较范围中多个路线引用同一套系 | 仅套系名称加粗，不表示主线、必读或已完成；图鉴按全部路线，阶段对照按当前同排关联阶段计算 |
| 重叠级别 | 当前比较范围中有实际交集的具体级别 | 仅对应级别片段加粗，其他级别、数量和限定不跟随加粗；不是整阶段等价 |
| 阅读状态 | 未开始、进行中、已完成 | 依据个人真实记录；未开始中性、进行中琥珀、已完成绿色。状态文字始终保留，不以用途色替代状态 |
| 类型、版本、主题、作者 | 素材类型、实际出版版本、内容主题、来源路线 | 独立的说明或筛选维度，不由其推断主辅线、难度对应、选读要求或完成状态；作者色点仅区分作者 |
| 引用数量、册数 | 数字引用图标表示阶段引用次数；册数表示当前筛选范围的读物总量 | 两者不得混用；未知册数不补猜测百分比；引用图标的解释统一在ⓘ中 |

用途只有主线、辅线、未标主辅。原文“推荐”保留为用途说明，不再单列“特色推荐”角色、颜色或排序；未明确主辅的推荐材料仍为未标主辅，不删除书目或修改个人记录。历史`featured`仅在公共模型中兼容为`reference`。

用途归属以“路线＋资料版本＋阶段＋原始引用”为单位。同一套系可有不同用途；无原文依据时统一为“未标主辅”，保留原用途与来源，不把分支、类型或共用程度解释成主辅线。

主线表示主要材料，不能自动解释为每套、每册全部必读。庆爸常规4的Little Fox主线明确“选2–3部”，常规5明确“任选2部”；这些要求与主线角色同时成立。缺少选材说明时不额外生成“选读”“任选”“必读”要求，也不把完成率当作能力晋级条件。

廖彩杏逐本完成按用户要求采用二态图标例外：空圈表示未完成、圈内勾选表示已完成，点击切换，不显示状态文字；真实按钮保留完整`aria-label`、`title`、`aria-pressed`与键盘焦点。图示130本、52周与详情共享同一记录。其右侧空心／实心星标独立表示是否已手工标记“完整内化”，默认亮黄色描边配白色半透明内填，标记后实心亮黄色，再点可取消；沿用英语记录与同步备份，星标不改变完成数量、不表示独立阅读，亦不借用收藏含义。其他素材继续遵守上表。

廖彩杏52周的复习安排是时间表维度：原表reviews中全部复习周统一浅紫底、虚线边框，选中深紫底、实线边框；普通引入周保持原色。排列Tab后统一清单图标的周次图例，说明同一复习段各周共用书目及选中样式。颜色不表示用途、难度或个人完成状态，Tab无障碍名称与提示同时说明复习范围。

SSS现有标签栏的葫芦数字表示《慢葫芦发声书：听儿歌学英语》福建科学技术出版社52页版（ISBN 9787533574901）的印刷页码。绿色表示页码／同曲目对应；橙色表示改编或同曲调关联，可能不同歌词，不保证同一录音。显式对应、关联类型、逐条依据与用户提供的2–51页完整手录集中在`sss-songs.json.soundBook`，不自动模糊匹配或根据目录顺序推算页码。葫芦为可点击气泡入口，手机可查看书名、页码与差异，电脑悬浮为补充；现有ⓘ统一解释颜色、版次与记录边界。慢葫芦Tab独立50首按页码排列、单独勾选，复用现有歌曲记录／保存／同步／备份，不计入SSS“全部”42首和原分类进度，不与同名SSS或廖彩杏书目共享状态。廖彩杏工具栏葫芦打开同一完整列表。

## 逐项用途证据契约

每条用途以“路线＋资料版本＋阶段＋原始引用”为核查单位，显式保存 `roleEvidence`，由公共模型提供给各页面，不在视图中重新推断。同套系、同名素材或同阶段内的其他引用已核定，不代表本次引用已核定；修改证据与展示角色不改原始 `material.role`、来源、级别、稳定ID或个人记录键。

| 字段 | 含义与维护要求 |
| --- | --- |
| `status` | 只用 `confirmed`（已取得足以核定本次用途的明确依据）或 `unresolved`（所列资料已核查，但本次主辅尚未核定）。检查过（checked）、找到书名或读过整表均不等于角色已确认；尚未实际核查不得虚填核查日期或描述为已核查 |
| `kind` | 只用公共分类 `main`、`auxiliary`、`reference`，分别对应主线、辅线、未标主辅；尚未核定时保留 `reference` |
| `usage` | 保留该次引用可读的原文用途或栏目，例如“闪卡式绘本”“平行拓展”；它不是新增的全局角色 |
| `basis` | 说明本次核定或暂未核定的理由、适用范围及必要限制，不能仅写“同系列”或“已查过” |
| `checkedAt` | 本次实际核查日期，使用 `YYYY-MM-DD`；不能借用资料发布日期或其他条目的核查日期 |
| `sources` | 逐条保留 `sourceId`、`page`、`quote`、`note`：资料ID、具体页／图位置、可核对原话、范围或关联说明。不能把本站推断写成原话；未取得明确主辅原话时保留所核栏目及未能核定的说明 |

“未标主辅”仅表示本次引用尚未核定，不能写成“作者没有分类”或“作者从未划分”。已核查（checked）与已核定（confirmed）的区别应在来源说明中可查，不能通过填色让已查未定项看似已确认。

许密杉六阶段全部读物、闪卡及动画／儿歌的引用均维护逐项核查记录。第3–5阶段海尼曼GK70 A／B／C、第6阶段牛津树3–5及对应辅线的核定通过`roleEvidence`读取，不在模型中硬编码阶段ID来补角色。前两阶段及动画栏尚无明确主辅依据的引用保留`unresolved/reference`；路线标签、进度分项和图鉴使用明细均引用相同结果。

许密杉六阶段表与全景图的阶段、词数或级别范围不一致时，禁止整表复制角色。只有核对具体材料、级别范围、原文用途及对应关系后，才可逐条采用跨资料证据，并在 `basis`、`sources[].note` 写清范围和差异；未对应的级别继续待核。原文明确的“平行拓展”与“辅线”同义，公共模型输出统一的`auxiliary`用途及“辅线”显示名称；路线全景、两进度页、图鉴、用法摘要、提示和关系图共用辅线颜色、图例与交互。`materialRole().usage`与各页面用途短文案统一经`EnglishModel.materialUsageLabel()`生成，不再把同义原词作为第二个分类显示；`roleEvidence.usage`、原文引述和出处保留原话供核对。历史`parallel`字段也可能只是整理出的并行安排，未核定时不能仅凭字段名变成辅线。辅线不等于“可选／任选”，不能自动生成选读要求，也不改变个人阅读进度状态。

## 交互与布局

- 阶段对照以正文容器720px为三列门槛，更窄时单路线阅读；不以900px导航断点决定对照列数。容器变化与作者切换沿用公共阶段和折叠状态，不能用缩小正文字号来塞入三列。

- 路线导航只保留一排作者与末尾的模式切换图标、ⓘ图例，不额外渲染“对照内容”作者Tab、整行模式按钮或基准解释句。作者切换复用`EnglishModel.libraryStageForRoute()`的公共对应规则，定位目标阶段；找不到对应则按目标路线首阶段浏览，不称其等价。默认阶段对照，图标可往返独立排列，保留所选阶段及全部展开状态。窄屏聚焦所选作者，宽屏三列对照；阶段栏继续单行横滑。

- 图鉴工具栏顺序为路线、阶段、主题、类型、状态，再接多路线共用及其余工具。类型与状态直接显示原生选择器，移除合并筛选气泡；当前值、筛选高亮和操作焦点随重绘同步。按内容宽度排列，窄容器自然换行，不截断选项或产生横向页面滚动。

- 用途、选材、类型等普通标签是说明，不添加按钮外观、悬浮点击手势或无意义Tab焦点。
- 点击素材名称或封面查看详情，点击ⓘ查看图例、选材要求和来源；展开收起使用＋／−，不让普通标签承担多个动作。
- 素材详情顶部小封面在左，完整标题在右，类型标签紧随标题；关联地图使用带完整提示的图标按钮，放在标题下方、封面右侧，不在正文重复。封面用于识别当前素材，可点击放大；不显示缩略图下方的出处链接，也不在下方另设“封面与图片出处”折叠区，来源元数据保留。无图时标题自然占满，长名称完整换行；全部套系共用该布局。
- 可操作状态使用真实按钮，保留描边、箭头、完整`aria-label`及键盘焦点；不可操作状态使用文字或标记，不能仿造可点击按钮。路线关联状态只展示派生结果，点击查看各阶段记录，不独立改写状态。
- 历史好价统一收进素材完整详情；卡片不再设置独立好价ⓘ入口，点击封面或标题后按需展开。报价按容器宽度紧凑分列，只展示级别／组合、价格、单位及必要的版本和适用范围结论；不展示作者、核对日期、原文、出处说明、原图核对或原笔记链接，也不为出处设置逐条展开。来源数据保留用于维护核查，不混合不同版本。
- 图鉴卡片默认封面视图；套系及主题筛选后的单册共用当前布局选择，过滤、清除与加载更多不改布局，单册结果也保留布局切换入口。不提供新增其他素材或收藏功能，全量展开／收起用向外／向内角箭头；已有个人素材继续保留查看、编辑与进度。
- 封面网格按容器保留正常列宽，筛选只剩一项或末行不足时不把卡片拉满整行；套系和单册共用此规则。单册图片允许在封面框内收缩，按原比例完整显示，不裁掉封面内容。
- 图鉴单册封面卡的完成勾选和信息按钮紧凑叠放在封面右下角，完成框18px、信息按钮20px，使用半透明浅底保证可辨识，不占标题宽度。两控件保持独立交互、来源颜色与键盘焦点；列表和详情沿原布局。
- 图鉴排序由`EnglishModel.sortLibraryMaterials()`统一生成：未指定阶段时优先当前路线听力执行主表，补充资料只作兜底；指定阶段后按所选阶段排序。全部路线按有据听力区间先后排列，香蕉妈妈按素材重合度关联排序锚点，不直接比较各作者的阶段序号；筛选路线后按其执行主表顺序。当前筛选内最早的阶段优先，其次按该阶段主线、辅线、未标主辅排列，同序稳定保留原顺序，无阶段关联的放最后。采用已有阶段顺序及公共用途判定，不用较晚阶段的主线抬升较早阶段引用，不从引用次数或书名推断。套系与主题单册、列表与封面共用同一规则。
- 图鉴卡片保留完整标题，标题旁不再显示类型图标；类型筛选与详情类型标签保留，列表、封面和既有个人素材共用此规则；引用数与状态、展开统一置于次要操作栏。卡片不展示册数与数量入口，点击标题或封面后的详情统一在“册数信息 · 数量与单位”折叠行展示当前筛选合计，展开查看公共级别、版本、范围、完整性及证据，不将目录覆盖冒充完整全集，也不重复另列总量。
- 卡片路线使用明细的阶段、级别与册数横向紧凑排列，能同行就同行，空间不足时自然换行，不固定拆成三行。
- 两路线进度素材统一通过`EnglishPractice.sortMaterialUnits()`按分级、绘本、其他排列，同公共套系连续，保留系列首次出现顺序及组内级别顺序；单项完成状态不打散套系，庆爸父子层级保留。
- 路线阶段栏是作者选择下的二级导航，不再显示“阶段推进／能力分支”标题行。按钮约32px高，文字沿用当前作者色，选中用浅色底及下划线，与上方44px作者按钮区分；保持完整键盘焦点。阶段按钮始终单行，按文字自然宽度排列，超宽只在该栏横向滑动；逐本阅读目录的书号、级别、书名与句型能同行就同行，空间不足自然换行，不固定把句型另起一行。
- 阶段栏首项“全部”复用公共阶段展开状态，连续展开当前路线全部阶段；选择具体阶段恢复单阶段查看。“全部”和具体阶段互斥选中，阶段对照与独立排列共用逻辑，不在模式工具栏重复设置展开／折叠全部按钮。
- 标签按内容自然换行，不固定增高，不截断长中文或英文名称；说明字号至少12px，正文与表单遵守既有全站规则。
- 路线阶段卡中的素材标签全部展示，阶段对照与独立排列使用同一规则，不按条数截断，不显示“＋N项完整资料”。
- 图例默认通过ⓘ按需展示，各页面调用相同内容；短气泡支持外部点击、Escape关闭及焦点恢复，详情浮窗沿用共享关闭与焦点约束。
- 选材完整要求在阶段ⓘ中列出；材料标签只保留短要求，不为增加说明另占一整行。

## 代码入口

| 职责 | 唯一入口 |
| --- | --- |
| 用途分类与展示名称 | `english/model.js`的`materialRoles`；`getStageMaterials()`统一提供`role.kind / label / usage / basis / selection` |
| 用途依据与选材要求 | `materialRole()`按该次引用判定；`materialUsageLabel()`统一同义用途的显示；选材仅读取原文明确要求，不按分支推断 |
| 逐项用途核查 | 每次原始引用的`roleEvidence`提供状态、核定结果及可追溯来源；已核查不冒充已核定 |
| 名称、级别、共用加粗、选材短标 | `english/material-ui.js`的`create().name()`和`title()` |
| 用途短标与图例 | 同一组件的`roleTag()`和`legend()`；页面不得复制分类表或另写解释 |
| 用途色与标签样式 | `english/styles.css`的`.material-role-*`变量、`.material-role-key`及`.material-selection` |
| 状态与真实记录 | `english/practice.js`的派生数量／状态模型；`english/app.js`的`resourceStatusControl()`共用交互 |
| 两级主题／场景及原标签映射 | `english/data/topic-taxonomy.json`；`english/topics.js`的`roots/children/entryTopics/expand/matches/options` |
| 页面构建 | `english/build.py`加载公共组件，重建普通入口、离线单文件与站点发布包 |

新角色须先补来源及模型定义，再统一更新公共组件、样式、ⓘ和本规范，不能在单个页面添加私有分类。原始`material.role`、级别、来源、稳定素材ID及`unitKey`不因文案或样式改变。修改后验证各路线、两进度页、图鉴两种视图、详情及宽窄屏；源码和生成页都要更新。本规范不代表相关修改已发布。

逐册封面按书名与版次逐本核对并保留来源页和核对日期。不同版次不共用未经确认的图；未取得可用单册图时使用套系图且显式标注，不将套装图描述为单册封面。

完整逐本目录与册数摘要分工：册数入口保留具名级别和分母；素材名称、进度数量与状态入口可查看同版完整书单并标记已读。目录由公共出版分项显式映射生成，缺册时不声称完整；不同版次分开切换。同阶段不同级别按入口的公共范围定位，不能仅按阶段或名称猜级别；书单勾选、路线数量、小花生事实共用同一公共单册ID及去重规则。

路线数量尚不能核定时，由公共`EnglishLibraryBooks.quantityReference()`显示已知具名范围（如整级30本、2套各15本、套装12本），具体版本和欠缺对应放在数量提示及ⓘ，不再仅显示“范围待核／目录N本”。这些参考不进入阶段分母；虚构／挑选子集必须逐册核定，不能为显示总数而使用整级、其他版次或平均拆分数量。

`directoryMatch`可用`edition/level`限定同版目录，并以显式`bookIds`取有据的分辑或基础故事子集；各条件取交集，不按题名或书号猜成员。同册可以属于基础选本与含增补目录，仍共用一个单册ID与完成事实，各范围分别计算分母。相互包含的出版入口以`includedIn`注明，图鉴册数摘要不重复相加；同一计划内部有重叠或缺册时不生成伪完整书单。只有出版简介中文目录的单册可手动勾选，未核到单册外部身份前，不将套装ID、套装封面或整套已读投影为单册事实。

进度页的可点击逐本数量沿用普通数量的视觉口径：完成数16px，分母／单位与百分比12px，细进度条3px；以描边和箭头表示可点击，不把数量、分母与百分比全部排成相同字号的文本按钮。阶段独立完成只改变阶段标记，不能把素材进度条涂满或改写为100%。

两路线进度素材名称旁通过公共组件`materialUI.typeTag()`显示原有素材类型，绘本、分级、动画、儿歌、闪卡、其他按已有`resource.type`读取；不按名称重判或把儿歌、闪卡强并为其他。类型为12px中性说明标签，与主辅线用途、个人状态分别表达，不增加点击行为。

阶段卡上方已显示进阶条件时，若下方流程推进内容与其相同，不再重复显示“进入下一阶段的条件”及随附“下一阶段”入口；阶段导航继续承担切换，独有的流程提示仍保留。三路线的对照与独立排列共用`stageFlow()`规则。

路线阶段卡通过`materialUI.roleGroups()`按主线、辅线、未标主辅顺序连续排列全部素材，各类内部保留原顺序，不显示用途分组标题或强制另起一行。用途仍由每次引用的`role.kind`提供颜色，按钮的无障碍名称、提示和ⓘ图例保留文字含义；不改角色判定。活动和音频等执行说明独立标为“同阶段安排”，表示时间组织，不表示辅线或另一组主线；`flow.parallel`不参与角色判定。对照与独立排列共用此规则。

阶段对照的“素材重合参考”与共用级别明细默认折叠，按需展开查看全部素材及双方原页；复用`readingFold()`按双方阶段和关联模式保留本轮展开状态，普通重绘不重置，不另列重复的参考标题。

完整阶段对照卡不在底部重复展示标题与目标中已有的词量对照；阶段原有目标、匹配依据数据及按需共用素材明细保留。

两路线进度的数量输入、逐本书单和歌曲进度共用同一行网格：完成数16px、单位／分母和百分比12px、进度条3px，数字与单位起点、进度条和百分比统一对齐。可编辑数字保留输入框；可打开逐本／歌曲清单的整块控件显示描边和右箭头。未知总量仅显示数量与单位，不虚填百分比；数量与版本说明ⓘ一律紧随标题区的类型及用途标签，不因总量已知与否移到进度区。

路线版次尚未选定时，公共级别匹配结果只有一个有总量的目录则默认采用，直接显示总册数并可打开逐本勾选；多个候选才提供“选目录”。默认取值由`EnglishPractice.defaultBookScope/bookScope`统一派生，不写入私人选版、不冒认为作者选版；明确保存的既有版本及自定义范围优先，保留当前条目原无分母数量，不跨级别借用。补分母不改变分项稳定键，不把未匹配的其他套装强行当本级目录。不同系列的未确认简称以`resource-volumes.json`的`catalogAlternatives`明确提供核对入口，保持原素材ID、来源和旧记录独立，不据候选关系生成别名或迁移进度。
