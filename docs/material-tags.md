# 英语素材标签与图例规范

本规范覆盖路线全景、阶段详情、许密杉／庆爸进度、素材图鉴的列表与封面视图、套系明细。新增页面沿用同一模型与渲染组件。成长能区色、作者身份色保留各自含义，不转作英语素材用途色。

## 含义与视觉

| 维度 | 分类与含义 | 视觉与依据 |
| --- | --- | --- |
| 阶段用途 | 主线、特色推荐、辅线、未标主辅 | 主线蓝色，特色推荐琥珀色，辅线灰绿色，未标主辅中性灰；文字、用途标签、用途背景及单项进度条共用该次引用的颜色变量 |
| 选材要求 | 原文明确的选2–3部、任选2部、挑选、可选等 | 单独的中性虚线短标签，不新增主辅线类别；级别文字已包含同一要求时不重复显示，完整原文仍在ⓘ中列出 |
| 共用套系 | 当前比较范围中多个路线引用同一套系 | 仅套系名称加粗，不表示主线、必读或已完成；图鉴按全部路线，阶段对照按当前同排关联阶段计算 |
| 重叠级别 | 当前比较范围中有实际交集的具体级别 | 仅对应级别片段加粗，其他级别、数量和限定不跟随加粗；不是整阶段等价 |
| 阅读状态 | 未开始、进行中、已完成 | 依据个人真实记录；未开始中性、进行中琥珀、已完成绿色。状态文字始终保留，不以用途色替代状态 |
| 类型、版本、主题、作者 | 素材类型、实际出版版本、内容主题、来源路线 | 独立的说明或筛选维度，不由其推断主辅线、难度对应、选读要求或完成状态；作者色点仅区分作者 |
| 引用数量、册数 | 数字引用图标表示阶段引用次数；册数表示当前筛选范围的读物总量 | 两者不得混用；未知册数不补猜测百分比；引用图标的解释统一在ⓘ中 |

用途归属以“路线＋资料版本＋阶段＋原始引用”为单位。同一套系可有不同用途；无原文依据时统一为“未标主辅”，保留原用途与来源，不把分支、类型或共用程度解释成主辅线。

主线表示主要材料，不能自动解释为每套、每册全部必读。庆爸常规4的Little Fox主线明确“选2–3部”，常规5明确“任选2部”；这些要求与主线角色同时成立。缺少选材说明时不额外生成“选读”“任选”“必读”要求，也不把完成率当作能力晋级条件。

## 交互与布局

- 用途、选材、类型等普通标签是说明，不添加按钮外观、悬浮点击手势或无意义Tab焦点。
- 点击素材名称或封面查看详情，点击ⓘ查看图例、选材要求和来源；展开收起使用＋／−，不让普通标签承担多个动作。
- 可操作状态使用真实按钮，保留描边、箭头、完整`aria-label`及键盘焦点；不可操作状态使用文字或标记，不能仿造可点击按钮。路线关联状态只展示派生结果，点击查看各阶段记录，不独立改写状态。
- 标签按内容自然换行，不固定增高，不截断长中文或英文名称；说明字号至少12px，正文与表单遵守既有全站规则。
- 路线阶段卡中的素材标签全部展示，阶段对照与独立排列使用同一规则，不按条数截断，不显示“＋N项完整资料”。
- 图例默认通过ⓘ按需展示，各页面调用相同内容；短气泡支持外部点击、Escape关闭及焦点恢复，详情浮窗沿用共享关闭与焦点约束。
- 选材完整要求在阶段ⓘ中列出；材料标签只保留短要求，不为增加说明另占一整行。

## 代码入口

| 职责 | 唯一入口 |
| --- | --- |
| 用途分类与展示名称 | `english/model.js`的`materialRoles`；`getStageMaterials()`统一提供`role.kind / label / usage / basis / selection` |
| 用途依据与选材要求 | `materialRole()`按该次引用判定；选材仅读取原文明确要求，不按分支推断 |
| 名称、级别、共用加粗、选材短标 | `english/material-ui.js`的`create().name()`和`title()` |
| 用途短标与图例 | 同一组件的`roleTag()`和`legend()`；页面不得复制分类表或另写解释 |
| 用途色与标签样式 | `english/styles.css`的`.material-role-*`变量、`.material-role-key`及`.material-selection` |
| 状态与真实记录 | `english/practice.js`的派生数量／状态模型；`english/app.js`的`resourceStatusControl()`共用交互 |
| 页面构建 | `english/build.py`加载公共组件，重建普通入口、离线单文件与站点发布包 |

新角色须先补来源及模型定义，再统一更新公共组件、样式、ⓘ和本规范，不能在单个页面添加私有分类。原始`material.role`、级别、来源、稳定素材ID及`unitKey`不因文案或样式改变。修改后验证各路线、两进度页、图鉴两种视图、详情及宽窄屏；源码和生成页都要更新。本规范不代表相关修改已发布。
