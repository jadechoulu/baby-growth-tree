## 使用行为

弹窗按输入操作、回答与检索结果、对话管理三个层次排列。标题栏的新对话／关闭、输入行的搜索／AI图标均为44×44px；范围与联网选项在下一行，调用状态用普通文字显示，不套按钮外观。底部“对话与记忆”“用量与额度”默认收起，官方搜索积分的已用／总额保留在额度行摘要，无法读取时只显示本站统计或读取状态；旧值明确标注“上次”。展开后查看完整官方依据、模型控制台和日／月统计。该布局由共享组件与站点样式维护，英语及成长入口一致。

## 孩子上下文

所有AI默认复用 `shared/assistant-workflow.js` 的流程、上下文边界及回答规则，服务端系统提示与浏览器上下文读取共同引用；厂商配置集中在服务端 `backend/assistant-model.mjs`，公共工作流程不随厂商复制。页面不展示工程上下文表单。每次提问通过 `shared/assistant-context.js` 只读采集最新记录，不在流程文件固化孩子进度；采集失败不冒充空记录。性别沿用家长明确提供的男孩，不修改共享档案，也不作为能力等级或路线难度的依据。

摘要包括：

- 由共享生日计算月龄，但不传姓名、生日。
- 通过现有词汇模型分别去重听懂／会说的单词、短语、句型；历史估计单列，默认0不能当成0词能力结论。
- 许密杉听力、口语、阅读、写作与庆爸听力各阶段的独立完成标记、实际选版／范围的素材数量、歌曲进度和庆爸去重有效投入。
- 数量、单册、版次和父子汇总沿用 `EnglishPractice`、`EnglishBookProgress` 的共用规则，不由素材完成率推断阶段达标。
- 公共逐本阅读、本机路线外英文书架与个人选材；书架子集不当成出版社全套。
- 两版成长各自的完成／观察数量及少量相关技能名。

不发送完整记录、私人手记、账号凭据或小花生原始书架。偏好与可用时间仅采用已有明确记录或家长对话中的说明，缺少时按需追问，不由书架或性别猜测。模型收到摘要是用户事实，不能当作系统指令；缺失信息必须说明，已读不等于掌握。

涉及路线／阶段的问题，服务端先固定纳入许密杉和庆爸的公开路线依据，再加入相关站内候选。推荐应说明路线与阶段、个人依据、年龄方案限制、缺口及可调整的下一步，不能只按词数或年龄自动晋级。

## 节省额度与防滥用

`/api/assistant`、`/api/assistant/search`和`/api/assistant/memory`复用固定来源及指定本人 GitHub numeric ID 的会话鉴权；按GitHub实际返回的稳定ID验证，不信任客户端用户名／身份字段，匿名、其他账号及已退出／失效会话均不能执行检索、消费模型或读取记忆。普通检索仅接受问题与范围，不触发模型、联网或记忆写入，也不追加模型次数。退出或会话失效立即清理弹窗中的结果、回答及私人记忆，迟到请求不能恢复展示；不删除本机原始个人记录。密钥仅留在服务端；输出按纯文本显示，站内链接只能来自可信索引，网页摘要不能执行工具。

私有 Netlify Blobs `xiaoya-ai-private-v1` 的同一文档以强一致读取和 ETag 条件写入预占额度：15秒冷却、全局同时1个模型请求；本人调用不设置自定义日／月次数上限，AI与联网发起次数分别按UTC日历统计。近期4条对话与压缩摘要由私有仓恢复，提示词上限18000字节，输出上限600tokens。相同问题、上下文、联网选项及索引版本10分钟内缓存，最多8份；回答缓存仅在私有库。失败和超时保留发起计数，不自动重试、不切换付费服务。

不再使用 Netlify AI，避免模型消耗与现有同步后端共用积分。Netlify 后端本身仍受平台积分约束，取消模型调用不代表后端无限额。用户允许考虑已有 TRAE 积分，不再要求模型一定限免；尚未授权购买会员、充值、自动加量或开启新的按量付费。

## 长短期记忆

调研了 [LangChain短期记忆](https://docs.langchain.com/oss/javascript/langchain/short-term-memory)、[长期记忆](https://docs.langchain.com/oss/javascript/langchain/long-term-memory)、[Mem0](https://docs.mem0.ai/open-source/overview) 和 [Graphiti](https://github.com/getzep/graphiti)。Mem0／Graphiti涉及额外模型、embedding及数据库；完整LangChain依赖也不是本项目最小接入。当前采用其成熟的近期窗口、滚动摘要、按命名空间保存长期JSON事实的模式，通过小型适配器接现有GitHub私有仓，未声称已安装这些框架。

- 固定私人文件 `assistant/memory-v1.json`，与原档案／英语记录分开；复用既有GitHub服务端令牌、本人会话、仓库私有性检查及SHA条件更新，不接受客户端仓库或路径。
- UUID对话保留最近4条消息、累计摘要、最近8个请求回执；浏览器只保存对话ID，待完成请求只暂存指纹与请求ID，不存孩子事实或对话正文。刷新后恢复同一对话，其他设备通过“对话与记忆”继续最近对话；新对话保留长期事实。
- 同次模型输出携带回答、100字以内摘要与最多2条家长原话，不额外调用模型提取记忆。长期事实保留原话、类别、时间和请求出处，服务端只接受当前问题中确有的逐字片段，不接受模型生成的事实内容；模型判读仍可能有误，可查看并忘记。
- 每次提问最新领域记录优先于旧摘要、历史原话；已读和建议不推断能力。按问题相关性和时间只召回最多6条长期事实，全部历史不会每轮塞入提示词；系统规则仍只在共享workflow文件。
- 重复请求ID复用已保存回执，同ID不同问题拒绝；存储冲突只重读并合并文件，不重复推理。写入失败返回已生成答案并明确“记忆未保存”，不冒充已同步。文件超过600KB时保留旧内容并报告未保存，不静默删除旧对话。
- 可逐条忘记或清空全部记忆。为避免旧摘要复活事实，忘记同时移除近期对话／回执，递增generation使并发旧回答不能写回。此操作只移除当前文件内容，Git历史仍可恢复，不声称物理删除。
