# 进度控件与阶段数量核对

核对日期：2026-11-09。本轮为发布候选，按受保护PR合并后由main统一发布，实际结果以Actions及线上核对为准；没有获取本人最新书架、上传授权或部署云端同步。

## 共用实现

两进度页的逐本书单、SSS歌曲、数量编辑及父项汇总，均由`english/app.js`的`practiceProgressControl()`生成控件。共用完成数16px、分母／百分比12px、3px细进度条、外框及网格；数字仍可编辑，只有实际打开清单的入口带箭头。未定分母不显示百分比，具体参考及缺口留在标题ⓘ内。

数量继续由公共出版范围及`EnglishPractice`、`EnglishBookProgress`派生，页面不硬编码册数、不另建路线记录。通用规则已写入`AGENTS.md`和`docs/material-tags.md`。
