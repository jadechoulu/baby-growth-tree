# 主题与句型后续核读

## 全量书目补查与题名兜底

用户指出仅新增5册不足后，本批重新检查全部329个规范资源、3,816条原目录及70条阅读计划投影，共3,886条分版本书目，并接通廖彩杏、Hello、SSS／慢葫芦及私人“其他”的筛选。当前3,517条公共书目有内容主题，369条缺少明确依据；相对本次全量补查前的3,068条，实际新增464条、撤回15条误导性题名归类，净增449条。规则候选审计曾报告486条新增、17条撤回；该数字未考虑原有较强简介及独立已核资料，不能作为最终导入增量。原301条简介归类保留，其中一册删除“成为书与电影灵感”的宣传句所带来的电影误归。

明确书名现在参与全部单册兜底，并可在既有一级内补二级；不由书名生成句型。规则剥离套系／级别／出版品牌，排除纯编号Hello、人物与品牌中的动物词、习语、消防车中的“火”、Blastoff Readers出版品牌中的太空词，以及Busy Machines等系列名。每条兜底保留原题名、命中词与规则ID。含糊题名仍待补，不能为了凑满覆盖率随意指定主题；现有分类、身份、级别、版次、册数与阅读完成事实不因此变化。

私人覆盖使用已取得的197册／54组样本逐本检查，153册可按明确书名归类、44册待补（其中24册纯编号Hello）。这只是该私有样本的覆盖统计，不冒充当前云端书架；书名、外站身份、原始快照及个人状态均不进入公共审计。运行时“其他”始终从当前私人记录派生，支持一级／二级、套系及阅读状态取交集，套系详情也可按主题查看单册；未筛主题时保留套系排列。本人验证后，全素材主题结果可同样包括私人单册。

Hello120个Part与56首原卡童谣都有主题；童谣须合并`hello-rhyme-content.json`后审计，不能把裸索引缺字段误报为缺分类。慢葫芦50首中45首具主题（10首同曲目参考、35首明确题名兜底），另5首含糊；原42首SSS不改。廖彩杏130部作品共用公共资源分类，其中2部题名不足以确定内容主题。4套独立系列简介主题已恢复筛选可达：没有相应单册结果时显示注明范围的原系列入口，有单册结果时不重复整套；旧`catalog-aggregate`残留不恢复。

公共全量计数及逐套待补ID见[覆盖审计](material-topic-coverage-20261115.json)，可用`node scripts/audit-material-topics.cjs`重跑。导入器同时撤回配置已移除的自动误归，保留独立证据、未知字段及句型。本批发布状态以对应PR、main部署及线上文件回读为准；下文保留此前联网核读过程及证据边界。

最终验证：707项Node测试、10项导入器测试、22项分类规则测试及6项页面打包测试通过；普通入口、离线单文件及完整站点包均生成。重复导入输出SHA一致；3,816条原目录的非主题字段及目录顶层数据逐字段相同。实际本地浏览器核对了“艺术与音乐／电影”的单册兜底与二级补充标记，以及“其他→交通出行／陆地交通→套系Tab→书架详情”的8册筛选、1册套系结果、原有阅读次数与完成控件；核对后Fire Truck不再误归自然现象、Blastoff出版品牌不再误归太空。浏览器使用的是本机已有135册历史记录，不冒充197册样本或当前云端书架，不进行同步或完成状态写入。

先前84条逐册资料及8项系列范围，以及扫码验证后新增5册主题资料、其中8句引述及12项系列范围，均已接入本地公共主题库，完成构建、测试与页面验收，纳入本批发布范围。本记录接续2026-11-14审计，不将旧检索次数重新算作本轮正文核读，也不宣称全部系列原文已核完。
