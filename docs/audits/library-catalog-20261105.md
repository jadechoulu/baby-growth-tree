## 实现与验证

卡片默认封面视图，标题后跟类型图标，数字引用、状态与收藏等动作同排；数量按钮只显示数字和单位，版本、部分目录及未核范围移至数量弹窗说明。逐册目录优先单册图，缺图兜底带可见“套系图”标记。

出版参考范围可在全部素材中合计；没有版本对应依据时，不作为路线与阶段筛选后的分母。相同版本与分项去重，未知子集不借用全套数量。
