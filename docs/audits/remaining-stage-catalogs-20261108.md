# 后续阶段公共书目补全核对

核对日期：2026-11-08。范围：庆爸常规3–6及准桥梁、许密杉1000词；许密杉2000词当前无绘本／分级引用。接续[五个起步阶段](early-stage-catalogs-20261108.md)，只补公共书目，不刷新或重写本人已读。本批为本地修改，尚未提交、发布。

## 本批数量与共用方式

公共目录由1518条增加至3389条，新增1871条。其中1791条保留单册封面原URL，1779条有独立小花生公开身份；12条因同一外站记录已经用于另一具名目录而不重复绑定自动已读身份；80条暂缺单册封面和公开身份（大猫中文目录79条、汪培珽选本中版本未定的The Little Red Hen 1条）。全部既有稳定ID保留，无重复小花生公开身份。

单册仅维护于`english/data/resource-books.json`，出版版本、范围和数量仅维护于`resource-volumes.json`。图鉴、素材详情、两条路线的逐本书单及手工／已导入小花生事实复用同一单册ID、`EnglishBookProgress`和记录，不复制路线书单。新增外部身份只支持既有已读快照的匹配，不表示已经重新获取本人最新进度。

基础故事与含增补目录以`directoryMatch.bookIds`明确子集，共用单册但分别核算分母；`includedIn`避免完整范围和分辑重复累加。作者未定版本保持可选，虚构子集、Part划分不明时不借完整目录当阶段分母。新书仅核书目身份与范围，未核正文的主题保持待核，不凭题名补二级主题。
