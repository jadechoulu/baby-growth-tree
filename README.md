# 小芽 · 宝宝成长技能树

根据「宝宝技能树_A4_打印版_1.pdf」整理的网页，共 248 个技能点、239 条进阶关系，覆盖 9 个年龄阶段和认知、感知觉、粗大运动、精细动作四个领域。原 PDF 的第 5 页是精细动作横向续页。未补造原图中不存在的语言等领域。

当前代码采用 **GitHub Pages 公开网页 → GitHub 登录 → Cloudflare Worker → GitHub 私有记录仓库**。已有 Pages 地址为 <https://jadechoulu.github.io/baby-growth-tree/>；该地址仍是此前版本，不能据此认定本次云端登录和保存已经部署。Worker、OAuth 和私有仓库配置完成前，本版本只能浏览公开图谱。

## 使用

当前预览：<http://127.0.0.1:5317>。

在此目录启动：

```sh
codex-dev run -- python3 -m http.server 5317 --bind 127.0.0.1
```

通过 `codex-dev status` 查看服务，通过 `codex-dev stop` 停止。网页使用原生 HTML、CSS 和 JavaScript 模块，本地浏览无需安装前端依赖或构建，需要通过 HTTP 服务打开，不能直接双击 `index.html`。根目录 `cloud-config.json` 的 `apiBase` 为空时不提供登录或个人记录编辑；完整配置见 [发布说明](deploy/README.md) 和 [Worker 说明](worker/README.md)。

## 功能与记录

- 宝宝视角：登录后从私有资料读取生日，按真实日历自动计算月龄、定位当前阶段；支持前后按钮和触屏左右滑动，能够返回当前阶段。公开代码的默认生日为空。
- 按年龄看：独立选择年龄范围，按领域、完成状态和关键词查找技能。
- 技能全景：提供「这项技能的完整脉络」与「整个领域全景」。点击节点追踪全部上游和后续；下方单列直接前序、当前技能和直接后续，还可逐条阅读从原图起点到末端的完整路线。
- 蓝色箭头表示前序，粉色表示后续，紫色卡片表示正在追踪的技能；金色虚线补齐后续汇合节点所需的其他前序。领域全景可按能力分支筛选，仍保留跨分支的前序，不会因筛选断链。
- 画布支持拖动、滚动、缩放、一屏看全、定位当前技能及放大查看；按 `Escape` 退出放大画布。宝宝视角、年龄列表和技能详情均提供「脉络」入口。
- 登录并读取云端后，点技能旁的圆圈标记完成，再点一次回退；技能详情可改完成日期和自动保存成长手记。图中节点、完整路线、年龄列表和详情共用状态。
- 记录以唯一技能 `id` 为键，跨视角、跨阶段共用。跨年龄段「过家家、职业工具」只存一个技能和一份记录。
- 右上角「备份」管理云端同步、JSON 导入导出和旧记录迁入。导入先校验并预览，再确认合并；相同技能采用导入记录，其他已有记录保留。
- 宝宝资料、完成标记、日期和手记以 **GitHub 私有仓库**为主存储。`IndexedDB` 和旧 `localStorage` 记录只作为迁移来源，不再接收日常保存；少量查看偏好仍保存在本机。
- 右上角显示「正在同步 / 已同步 / 未同步」及错误状态。只有服务端确认 GitHub 写入成功且本页没有待保存修改时，才显示「已同步」。失败可重试或导出本页记录；仍有未同步修改时，离开页面会请求浏览器提醒。
- 原始 PDF 可从右上角「原始图谱」打开。年龄和进阶关系用于陪伴参考，不将进度作为诊断或评测结果。

原图 `31–36个月` 与 `3–6岁` 在 36 个月交叠。网页保留原文标签，自动定位时从满 36 个月开始进入 `3–6岁`；所有阶段仍可手动浏览。3–6 岁延伸节点保留原图内容。

## 身份与云端同步

未登录时可浏览公开工具外壳、技能目录和原始图谱，不能读取或修改个人记录。Worker 仅允许配置的 GitHub 数字身份访问同一份私有记录；当前本人账号为 `jadechoulu`，ID 为 `266516354`，部署时需明确配置，不是任意 GitHub 用户登录都能访问。

打开页面后，当前标签页有有效会话时会先校验身份、读取云端；没有会话则先登录。读取失败不会用空默认记录覆盖云端。云端尚无记录时，由本人建立资料或确认迁入，页面不会自动初始化个人记录。换设备或清除浏览器数据后，重新登录即可恢复**已同步**的云端记录。

完成、回退、资料和日期修改会进入保存队列；手记在停止输入约 1 秒后合并提交，避免每个字符都生成 GitHub 提交。请求串行处理，网络等待期间继续输入的内容会保留，并在确认版本上继续合并。页面重新获得焦点时，会在没有待同步修改的情况下重新读取云端。

多设备保存使用 GitHub 文件 SHA 版本检查，并按资料字段、技能的完成日期和手记进行三方合并。不同字段可自动合并；同一字段发生冲突时保留双方内容，要求本人选择后再同步，不用最新版本号直接覆盖另一设备。

网络失败、会话失效或冲突未处理时，当前修改暂留本页，不会被标为已同步，也不会改写到 IndexedDB 冒充云端成功。可重试、重新登录，或先「导出本页成长记录」保留包括未同步修改在内的 JSON；关闭或刷新前请完成其中一步，浏览器离开提醒本身不保证保存。

浏览器的 `sessionStorage` 仅保存当前标签页的 Worker 登录会话，`localStorage` 的 `xiaoya-growth-view-v1` 仅保存视角、年龄阶段、领域和脉络焦点。查看偏好仍按网页来源隔离。GitHub Token、OAuth client secret 均只放服务端秘密配置，不能写入前端或公开仓库。GitHub 私有仓库会保留提交历史，删除当前记录文件不等于删除历史资料。

## 从旧本机记录迁入

1. 升级或换地址前，先从旧页面导出 JSON，并保留原文件。旧 `xiaoya-growth` IndexedDB 数据库和 `xiaoya-growth-v1` localStorage 记录不再自动迁移或删除。
2. 本人登录并成功读取云端后，打开「备份」。同一网页来源下发现的旧记录可先导出、再「预览迁入」；换域名或设备时使用「导入 JSON 备份」。原有 v1 备份格式继续兼容。
3. 核对资料、完成数量和手记。确认后才合并到当前云端记录；相同技能采用导入内容，其余已有记录保留。若期间出现多设备冲突，继续逐项选择。
4. 等待「已同步」，重新读取并核对后再处理旧副本。迁入不会清空旧本机记录或修改原 JSON 文件。

后续可从语雀提供固定 Pages 地址的链接入口。直接上传 HTML 或嵌入的脚本、弹窗和沙箱权限仍需单独验证，语雀账号不会自动变成这份记录的同步身份。

## 内容扩展

`data/catalog.json` 是技能内容的唯一数据源。保持已有 `id` 不变，即可在更新内容时复用已保存记录。每个技能结构：

```json
{
  "id": "fine-roleplay-tools",
  "domain": "fine",
  "category": "使用工具",
  "stage": "s4",
  "endStage": "s7",
  "title": "过家家、职业工具",
  "parents": [],
  "sourcePage": 5,
  "guidance": "可选的陪伴说明",
  "enrichment": ["可选的启蒙活动"],
  "toyIdeas": ["可选的玩具候选"]
}
```

`endStage` 仅在技能横跨多个阶段时填写。`parents` 是原图箭头的直接上游，不会因前序技能未标注而锁定后续节点。`domain` 为 `cognition` / `sensory` / `gross` / `fine`；`stage` 为 `s0` 至 `s8`，与年龄阶段顺序对应。

`data/stage-resources.json` 为年龄段扩展内容，以阶段 ID 为键，同样支持 `guidance`、`enrichment`、`toyIdeas`。例如为 `s5` 填入：

```json
{
  "s5": {
    "guidance": "这一阶段的陪伴说明",
    "enrichment": ["活动候选"],
    "toyIdeas": ["玩具候选"]
  }
}
```

有内容时自动显示「陪伴与探索」，空字段不会显示占位区域。技能与阶段还可以增加其他字段，并在对应渲染函数中扩展展示。应用状态、技能目录和阶段补充内容分开保存，内容更新不会覆盖宝宝记录。

## 验证

```sh
node --test tests/*.test.mjs
node --check app.mjs
```

`lib/model.mjs` 负责月龄、阶段、范围技能、完成状态和备份校验；`lib/graph.mjs` 负责前后依赖、完整路线、跨分支前序和图布局；`lib/storage.mjs` 保留旧本机记录读取能力；`lib/cloud.mjs` 负责云端请求与三方合并；`lib/save-queue.mjs` 负责手记防抖、串行提交及在途编辑保留；`app.mjs` 负责视图、登录、明确迁移与备份。`worker/` 负责 OAuth、身份授权、会话和私有仓库读写。

`styles.css` 包含基础布局，`theme.css` 提供明亮的橙、紫、蓝、绿主题，`graph.css` 负责脉络图及桌面、手机适配。云端单测使用模拟网络和存储，不等于真实账号环境的 OAuth、跨设备恢复或线上部署验收。
