# 小芽英语 · 启蒙路线与素材地图

交付文件：[英语启蒙路线导航.html](../output/web/英语启蒙路线导航.html)。该文件已内嵌全部数据、封面裁图、34张原页预览与8份原始文件，可直接用浏览器打开，无需安装软件或启动服务。

`english/index.html` 是较小的目录版，需要与 `english/assets/` 一起保留，同样支持直接双击打开。与成长技能树在同一公开仓库的 `main` 分支维护，顶部可切换工具或返回共同首页。本地服务已存在，预览地址为 http://127.0.0.1:5317/english/ ；从工作目录运行 `codex-dev status` 可查看服务状态。

## 内容与使用

- 宝宝视角：初始生日为空、听力词汇为0，个人资料由访问者自行设置；按上海日期计算实际月龄，可修改档案。四步示例活动为整理建议，活动详情能打开对应素材及原作者阶段。新增阶段执行表的参考说明：当前优先听词指物、TPR和短时亲子共读，原表自然拼读、书写和长音频日程不自动进入宝宝建议。
- 路线全景：默认打开“阶段对照”，先用速览查看一对多关系，再展开两侧具体素材、原文级别和原页。可切换对照起点；明确区分级别相同/重叠、同套系共用素材、同套系不同级别。三条完整路线支持默认“阶段对照”和原“独立排列”两种模式。香蕉妈妈6阶段、庆爸7阶段；许密杉可切换原6阶段听力线、阶段执行表4阶段执行表、听说读写全景图4领域10分支，合计33个阶段/节点。切换许密杉查看视角后，正反向阶段对照同步切换；全景图在两种视图中均按领域分组。每个节点可查全部素材、方法、原页与同版本前后节点。阶段执行表保留每阶段3个月、29项原文任务及频率、时长、使用方法。香蕉妈妈保留2/3岁、4/5岁、6/7岁零基础起点的各阶段时间表。
- 素材图鉴：398条来源素材记录归并为213个系列，保留全部版本、级别、角色和来源。共用卡醒目标出路线名称，每条路线按版本直接列“阶段 → 原文级别”；可仅筛选多路线共用。详情顶部提供路线/版本/阶段/级别/原页对照表，按原文展示已有级别，不补造级别。按绘本/读物、分级、动画、儿歌、闪卡、其他筛选，支持关键词、路线与当前浏览起点筛选、收藏和素材小记录。
- 关系地图：追踪同素材跨路线引用、同阶段读物与动画组合、平行拓展；点节点可继续追踪。年龄索引与阅读难度参考独立展示；阅读难度可按RAZ行查看原图合并单元格的覆盖范围。
- 原始资料：完整保留八份来源，可翻页、放大或打开原始文件。封面裁图与无封面的图示明确区分。
- 档案、收藏和记录保存在当前浏览器的 `localStorage`。可在宝宝资料中导出JSON备份；不同浏览器、网站地址与单文件地址各自保存。目前不提供自动同步或备份导入界面。

## 出处与边界

1. 香蕉妈妈PDF：18页，第9/10页重复；6阶段×3年龄起点计划，原文没有听力词汇门槛。
2. 许密杉PDF：第1页含全部路线；第2页只有署名水印，无遗漏阶段。200、300等词数是“目的”栏的阶段目标，没有年龄门槛。
3. 庆爸PDF：6页，适用3–4岁常规路线；词数为积累目标。新版测试Phase、成长计划Phase分别保留，投入时间与400H/480H累计标准不混算。当前低龄宝宝仅把此路线作未来参考。
4. 书籍年龄路线概览JPG：无可确认作者，17套系独立参考；所列年龄不等于必须达到的进度。
5. 分级难度对照PNG：无可确认作者，阅读难度不是听力能力等式；按原图覆盖范围显示，不转换为宝宝月龄、听力词数或测试Phase。
6. 杉杉老师英语阶段执行表路线规划PDF：4页，每阶段原计划3个月；保留听力、拼读、认读、书写和自读桥梁任务。第1阶段“不需要读和写”与字母书写行的冲突、第3和第4阶段的频率差异均保留说明。Basic Reading的200/400/800词属于教材层级，不与宝宝听力词数等同。
7. 阶段执行表四阶段思维导图：同一计划的图解，不重复建立阶段；与PDF不同的命名及省略细节分别说明。
8. 英语通关全景图：按听力、口语、阅读、写作分组；听力词数仅保留原图节点标签，阅读泛读1000–8000词为阅读积累目的，写作100词及400–800词为作文长度，三者不互换。全景图听力1000词列桥梁书，与原六阶段表保留为独立口径。

三条路线没有原作者给出的精确阶段等价表；网页用同素材引用和明确的组合建立关联，不制造跨路线等号。未提供的媒体、分册内容、购买渠道不补造；原文不确定或疑似笔误保留说明。
