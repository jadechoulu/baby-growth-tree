# 阶段判定先于素材关联

用户纠正：必须先核对各路线当前阶段的判定规则，以一致的能力和尺度确定阶段关系，然后查看素材，不能反向推导。

## 实现边界

- 删除以素材交集数挑选香蕉妈妈主要对应阶段的逻辑。
- 模型 `stageReferences` 只包含有依据的听力词汇目标参考与明确的起步方式参考。主正文、速览、摘要和同排素材标记复用此集合。
- `matches` 保留独立素材关系与双方级别、角色、出处；其他素材关联默认折叠，不把整阶段作为主对应。
- 现有香蕉资料没有与听力词数一致的量化尺度，不给后续阶段补造词汇范围；Pre起步参考不表示能力或任务相同。
- 听力、阅读等能力维度分开；庆爸测试进出要求和许密杉节点目标分别保留，粗略词数参考不冒充执行要求或晋级等价。
- 保留三位作者完整路线、窄屏Tab、稳定ID、素材排序、级别交集显示及个人数据。

## 验收契约

- 没有同尺度判定依据，即使大量或全部书目相同，也不能生成主阶段对应。
- 增删、替换或重复素材不改变既有阶段参考；材料关联仍能双向访问。
- 许密杉与庆爸原有双向听力词数参考保持；阅读词数不被混入。
- 桌面及窄屏检查香蕉后续阶段无主对应卡，其他素材仍可展开并打开详情；Pre参考与词数参考可见。
- 构建普通英语入口、单文件和统一站点；本地验收后不提交发布。

## 2026-10-29 补充：允许有依据的跨尺度对照

不把相同原生尺度当成唯一条件。尺度不同时继续查找并核验跨尺度校准，记录适用范围及证据等级；取得可靠依据后先接入模型，再进入统一stageReferences。当前研究见 `../cross-scale-research/research.md`。素材交集不能代替校准证据，尚未验证的规则不改变阶段关系。
