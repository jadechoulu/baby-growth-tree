# 作者、阶段与并行能力的阅读组织

2026-11-03，本地实现，未提交发布；与本批“展开全部”一起维护。

## 已实现

- 顶部先选作者，再点击听力阶段节点；各宽度默认聚焦一个阶段，展开全部可连续阅读。宽屏阶段对照仍并排三路线，窄屏行内作者标签只切换本阶段的对应内容。独立排列只读顶部作者。
- 听说读写收进“按能力查资料”。只有听力阶段用顺序连接符，其他能力显示分支与原文方法；无独立阶段的作者不借用其他路线节点。
- 阶段内容区分当前主线、同时进行、其他能力加入参考、进阶条件或后续浏览说明。素材角色与顺序沿用既有模型，点击素材、阶段详情、SSS及原页仍可访问。
- `getStageFlow()`只使用本阶段活动、当前年龄case和显式来源说明。许密杉闪卡与绘本并行，口语可并行、读写另查条件，不以听力词数推导启动；庆爸保留原文时数及测试条件；香蕉妈妈未来跟读/自拼按当前case原文加入位置显示，低龄标参考，年龄未知/超范围不借用其他case。
- 选择阶段会打开该阶段的对照内容；批量折叠、作者切换、普通重绘、模式切换与宽度变化保留相应浏览选择。新能力说明折叠保留本轮状态，不写个人存储。
