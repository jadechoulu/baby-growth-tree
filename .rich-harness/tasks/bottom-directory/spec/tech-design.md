# 窄屏分类目录从底部展开

## 需求与实现

成长、英语及后续分类的目录在不超过 `900px` 时，从屏幕底部向上展开。原侧向抽屉限制阅读宽度，改为全宽、内容自适应且最高 `85dvh` 的底部面板；桌面常驻侧栏沿用原实现。

只修改 `site.css` 的共享目录样式，沿用 `shared/site-shell.js` 的原生 `dialog`、导航回调和关闭逻辑。标题及关闭按钮留在滚动区外，目录内部独立滚动，底部预留安全区，长名称可换行；减少动态效果时关闭入场动画。分类选择器保持居中，不改个人档案、领域数据或存储。

英语普通入口、单文件导出与公开包均通过既有构建重新生成。根入口和站点首页更新共享样式缓存参数。

## 验收契约

- 成长、英语分别覆盖 `320 / 375 / 390 / 768 / 900px`，面板左右贴边、底部贴边、高度不超过可视区的 85%，内容无横向截断。
- 长目录内部可以滚动到最后一项；横屏 `740×360` 仍可读取并操作目录，标题和关闭按钮保持可见。
- 点击目录项执行原导航并关闭面板；关闭按钮、遮罩和 `Escape` 均关闭且恢复焦点及页面滚动。
- 模态期间不能操作背景页面；`900px` 打开后切换至 `901px` 自动收起，`901 / 1280px` 恢复常驻侧栏。
- 英语普通入口、单文件与发布包携带相同目录样式；站点首页、分类选择器不受影响。
- 运行现有 Node 模型/框架/构建测试、Python 英语发布测试及完整站点构建。共享构建目录的测试串行执行，避免产物互相覆盖。

## 状态

共享样式和长期规范已实现；浏览器证据保存在用户指定的育儿目录，验收结果以本任务提交与 PR 记录为准。
