# 窄屏保留完整领域进度

## 实现

- 领域名称、完成数量、百分比与进度条始终保留，移除窄屏隐藏百分比的规则。
- 按实际正文容器宽度调整：不超过 640px 时隐藏装饰图标，数量与百分比同排；不超过 400px 时百分比另起一行，避免满进度和两位数数量挤在一起。
- 四领域始终同排，不足时沿用卡片区局部滚动；辅助数值至少 12px，不变更进度计算及个人记录。

- 320、375、390、485、530、768、900、901、1280px 检查四项百分比可见，进度卡内部未截断、页面主体无横向溢出。
- 点击领域切换清单正常，阶段切换后四领域数量和百分比继续对应当前阶段；数量与进度条计算沿用原模型。
- JavaScript 语法检查、10 项图谱测试和统一站点构建通过。
- 核对原端口已有记录仍在，并通过原页面的导出功能另存最新 JSON 备份到用户指定的育儿 codex 目录。未向新端口导入，未覆盖或合并记录。
- 本机与线上云端配置均未启用。当前 GitHub 保存网站工程，个人记录按浏览器网站来源保存；不同端口隔离，不代表旧记录被清空。工程提交与记录同步是独立能力。
- 改动保留在本地，等待用户明确提交合并。
