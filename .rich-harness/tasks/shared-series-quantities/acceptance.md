# 公共套系册数与重复入口验收

核对日期：2026-11-05。工作分支：`codex/english/shared-series-quantities`。本批仅本地实现与验收，未提交、推送或发布。

## 实现

- 册数统一归入 `english/data/resource-volumes.json` 的套系、版本与级别分项；路线 `references` 只保存公共范围引用。
- 图鉴、路线进度及详情调用公共模型读取数量；历史素材通过 `catalogResourceId` 共用目录，不改个人记录键。
- 有来源的单级范围可组合；同版重复分项及 `includedIn` 嵌套包不重复计数。只有组合总量时不均分给各级。
- 已知出版数量与实际选版分开：没有选版的牛津树1级显示84／96本候选，选版后才将对应分母用于本人百分比。未知实际分母时只记录完成数量。
- 用户指出的三处数量资料合为唯一“数量构成、版本与来源”入口；删除数量摘要中的第二份构成表及素材详情外层重复的公共资料。
- 窄屏未知分母行省去“/ — 本”，候选数字紧凑显示，完整“可选版”含义保留在提示及版本选择弹窗。

## 补查覆盖与限制

全量审计166个书籍／分级素材，162个可显示有来源的数量范围，4个仍未取得能够确定同一版次的固定总量。公共目录159条，150条有公共范围或共享引用。逐项数据及未计入范围见 [catalog-audit.json](catalog-audit.json)。这些数字不表示162个品牌的全部出版书目已经完整核清；具名选本、已收录目录与全套总量仍分别说明。

典型核对结果：

| 素材范围 | 数量与边界 |
| --- | --- |
| 牛津树国内红标／无标选本 | 1级84、2级48；共用3／4／5级42／42／36；家庭版1–3级32本与学校版分别列出 |
| 牛津树国内橙标选本 | 1级96、2级54；共用3–5级不再加一份重复数量 |
| 海尼曼国内GK70 | 保留原70本选用范围和个人键；A43／B15／C12为该选本内部构成，与其他70本版次区分 |
| QPlay奇问妙想国 | 主故事绘本10本；活动书、贴纸及游戏组件不计入故事分母 |
| 学乐高频词读物 | 已核Nonfiction Sight Word Readers A–D各25，E&F等联合级各14；联合级不拆均分 |
| 学乐小读者外研2025版 | A–J组合282本；尚未取得逐级目录，不能据总包填出E级分母 |
| RAZ | 具名商家14级选本快照1243本；不作为在线平台全部书目的总量 |
| Saalin词卡 | 220张，单位为张，不显示成220本 |

仍无可靠固定册数的4项：

1. 培生（第六阶段）：原引用只有“培生5–6级”，没有唯一套系名、封面或ISBN，不能继承其他阶段启明星版次。
2. 大马泽单词本：私编整理本，未取得固定公开目录；零售BBC MUZZY套装不是同一身份。
3. 大马泽台词本：合订版本不同，零售12册／38册不能与原稿逐一对应。
4. 小狐狸台词本：平台持续更新且合订任意，没有唯一固定出版版次及总册数。

检索依据、出处、日期及限制均保留在公共目录，不以无来源的数字补齐空白。
