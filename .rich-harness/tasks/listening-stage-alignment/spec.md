# 听力词汇阶段对照

## 目标

用户指出庆爸常规1应与许密杉第一阶段对应，不能因为共用书籍也在500词节点默认展示。检查庆爸全部七个阶段，提供双向一致的词汇目标参考，同时保留素材关联。

## 实现约定

- 默认听力视图与全景听力分支的300、500、800、1000、2000词节点使用显式 `listeningTargetWords`。
- 相邻节点之间的范围只作为本站整理参考，与庆爸原文词汇目标区间比较；仅端点相接不算交集。
- 第一阶段对应常规1；500/800/1000词分别对应常规2/3/4；1000–2000词段对应常规5/6/准桥梁。
- 正文、折叠摘要和全阶段速览使用同一主对应规则。其他共用书籍可展开查看；素材原级别和双方原页保留。
- 词汇对应不依赖书籍交集，不改变个人档案、听力推荐、作者原文门槛及进阶条件。不以阅读词数或年龄推算听力对应。

## 验收契约

- 模型测试覆盖两种视图全部七个庆爸阶段的正反向对应，边界相接不串段，无共用资料也可对应。
- 保留常规1与500词节点的素材证据，但不列为主要词汇对应。
- 浏览器检查第一阶段、500词与2000词节点，切换庆爸起点反向查看；可展开其他素材、详情和原页。
- 检查320、375、390、518、768、900、901、1280px布局的标题、目标说明、展开内容和横向溢出。
- 重建英语普通入口、单文件及整站包；日常修改保留本地，不提交发布。
