# 成长清单与脉络工具栏

## 目标与实现

- 点击领域清单标题收起或展开技能；默认展开，切换领域、筛选、普通重绘与宽度变化保留本次浏览的展开选择，不写成长档案。
- 单领域清单占满正文；容器达到 700px 时技能双列，较窄时单列。技能标题可换行，完成圆按钮保持 18×18px。
- 删除“高亮区域是所选阶段……”说明及重复引导标题；定位本阶段、在技能全景展开为成长脉络标题后的两个图标按钮，保留无障碍名称、提示及键盘焦点。
- 不更改技能数据、记录、完成或回退逻辑、导航和英语领域代码。

- 真实浏览器验证 320、375、390、768、900、901、1280px：主体无横向溢出、标题无截断、清单占满、工具栏可达、完成按钮均为 18px。
