# 卫健委成长版本

用户要求：根据提供的 WS/T 580—2017 原件，在同一成长分类下增加卫健委版，现有内容明确为毛老师版。

## 实现契约

- 共用站点壳与全站宝宝档案；版本链接使用相对路径。保留 index.html 及旧深链接。
- 普通版本导航与详情项目对应分开。详情仅显示人工逐项核对的关联，支持双向及一对多，区分同类动作与部分相关，逐项说明差异。当前毛老师原图缺少完整量化通过要求，无已确认完全一致关系；独立及待核对项不显示对应入口，不跳另一版本首页冒充对应。关系保存在 shared/growth-references.js，不转换记录。
- 独立 health.html 入口、health.mjs、health.css 与 data/health-standard.json。五能区、28月龄组、261项完全沿用表A.1；附录B方法/通过要求按编号关联，保留两处原文名称及PDF页码、R/*标记。
- 提供宝宝视角、能力脉络、下一步、全量搜索和清单状态筛选；阶段用连续区间组织，原标准月龄保留在项目中，旧单月龄链接仍可恢复。五能区的完整月龄脉络支持定位、记录、打开详情；月龄序列不代表技能依赖，不画推测连线。
- 下一步按实际当前阶段及观察记录推荐，与预览阶段无关；保留当前、此前及已有进度以内的遗漏项目，各能区从最新已观察月龄继续其后首个未观察月龄组，不等待同组全部完成。无观察能区不提前开放未来，撤回后重新计算，搜索不越出推荐集合，下一步完整展示推荐项，能区不收起，不显示“继续查看”；宝宝视角折叠与全量搜索分批不变。月龄顺序不代表技能前置关系。详情展示原文方法、要求、同能区上一项／下一项及原件链接。
- 标准与使用方法只用版本标签旁的圆圈问号打开弹窗，不占导航页签；详情中叠加说明保留未保存观察、深链接及关闭后焦点。
- 宝宝视角与能力脉络提供所选阶段的“全部完成”，范围为该区间五能区全部项目，筛选不改变范围；保留已观察日期及所有手记，写入成功后禁用，撤回单项可恢复。宝宝视角每个能区清单标题旁增加独立的图标式批量入口，仅完成所选阶段该能区全部项目，状态筛选不缩小范围，保留日期手记，不切换折叠，完成后禁用、单项撤回后恢复。下一步与全量搜索不显示批量入口。
- 家庭记录为“已观察到／暂未观察到／未记录”，日期与手记；不自动计算正式测查分、智龄、DQ。不把观察数量称为达标率。
- 卫健委记录独立 IndexedDB xiaoya-health，独立同步 area=health，私有仓文件 records/health.json；旧growth记录、统计、备份不变。不复制或合并两套完成记录。
- 使用现有共享同步引擎的鉴权、首次预览、三方合并、持久回执和离线重试。后端先于网页发布，旧客户端忽略新增数据文件。
- 导入须校验标准标识、ID、状态、日期；预览后合并，不覆盖现有本机不同记录。备份仅包含本版本。
