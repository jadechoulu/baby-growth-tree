# 英语路线窄屏标签切换

2026-10-29

## 目标与实现

不超过900px时用许密杉、庆爸、香蕉妈妈三个标签替代三人纵向平铺。阶段对照在当前阶段行内切换作者，不改变起点、当前阶段、关联依据或素材交集；初始选起点作者，切换阶段保留选择。独立排列同样一次显示一位作者。宽屏恢复原有三列和单路线筛选，打印包含全部作者。

标签复用现有面板DOM，点击直接更新临时选择及可见状态，不重绘页面或写入个人档案；打开选中面板，保留内部筛选和折叠内容。使用tablist、tab、tabpanel、aria-controls、aria-selected及单一键盘停靠点；支持左右方向键和Home/End。详情及素材跳转保留原有行为，领域无独立节点仍可通过标签阅读原文方法。

## 验收结果

- 40项英语模型测试、JavaScript语法与Git差异检查通过；普通入口、离线单文件及完整站点构建通过。
- 浏览器实际切换三人标签，方向键切换正常；庆爸标签下点击下一阶段后仍展示庆爸对应节点。
- 实际打开培生套系详情并关闭，标签与当前阶段保留；阅读领域下香蕉妈妈原文方法正常展示。
- 阶段对照和独立排列均在320、375、390、768、900、901、1280px验证：窄屏只显示一位作者，901px及以上恢复三列，无整页横向溢出、标签或素材内部截断；往返跨越断点后选中面板仍展开。
- 原先紧凑素材标签样式保持；浏览器无运行错误。
