# 卫健委版交互与功能对齐

用户要求：卫健委版的交互、功能按照毛老师版组织。本批只在本地实现和验收。

## 对齐范围

| 毛老师版入口／行为 | 卫健委版处理 |
| --- | --- |
| 统一站点导航、版本切换、资料、同步与备份 | 沿用共享站点壳；移除重复正文视图页签，补本机保存状态 |
| 累计数量与百分比、领域进度条 | 全目录261项与各能区分别统计；小屏保留数值，五项同排，窄容器局部滑动 |
| 阶段、领域、状态、搜索与清单 | 连续阶段区间，五能区状态数量、一键清除，清单默认折叠并保留展开状态 |
| 紧凑技能行的完成、详情、脉络 | 完成按钮18×18，技能名称打开详情，脉络图标紧跟名称 |
| 图谱定位、清除、缩放、一屏看全、回到当前阶段、放大、图例 | 相同工具操作，原生弹层保障焦点与Escape；标准月龄序列不画依赖边 |
| 下一步、完成后推进与撤销 | 复用原标准五能区推荐模型，按阶段组织连续紧凑技能行，不折叠、不截断 |
| 单项／批量可回退，保留手记 | 最近一次操作可撤销；仅恢复仍匹配本次写入的字段，状态日期作为一组，保护并发修改 |
| 详情、资料与弹层返回 | 保留原文方法与要求、独立家庭观察表单；详情可进入定位脉络；说明叠加保留表单；关闭同步清理引用和深链接 |

## 保留的内容边界

- 卫健委版仍为五能区、28原始月龄组、261个稳定ID，不按毛老师版四领域重写资料。
- 月龄脉络只表示时间顺序，不宣称逐项前置依赖或测查等价。
- 两版记录库、备份、同步文件完全独立；本批不改鉴权或同步协议，不发布个人记录。
- 本地浏览器交互在独立未登录的 agent-browser 会话中使用测试记录，未改用户浏览器中的观察记录。

## 再次全面核对（2026-11-03，本地未发布）

用户反馈仍有多处细节不一致，本轮按毛老师版三个视图逐区核对，补齐以下部分：

| 功能区块 | 原有差异 | 本轮处理 |
| --- | --- | --- |
| 目录 | 阶段入口不完整，组织与毛版不同 | 三视图、完整阶段目录、资料与备份统一排列，阶段可直接跳转 |
| 顶部累计 | 只有数量/百分比 | 补紧凑进度条，各视图保留 |
| 阶段导航 | 只有选择器，批量完成另占一行 | 宽屏阶段按钮、窄屏选择器，箭头后放唯一全阶段完成；预览时可返回当前 |
| 能区 | 三视图都用进度卡，选择可退回全部 | 宝宝视角用进度卡；脉络和下一步用带项目数/可探索数的标签，统一单能区选择 |
| 宝宝视角 | 宽窄屏均先清单，重复阶段标题 | 宽屏图谱在前，窄屏清单在前；去重复标题和全量定位器，清单默认折叠 |
| 筛选与搜索 | 与清单分离，重挂节点会使搜索失焦 | 并入清单，连续输入保留焦点，清除恢复原展开状态 |
| 图谱 | 名称直接开详情，缺少解释/选中区分 | 点名称高亮并保留键盘焦点；解释开详情，圆圈完成，定位清除/缩放等保持 |
| 下一步 | 冗余状态筛选、分组与摘要稀疏 | 使用紧凑技能行、能区标签、月龄图例及同排摘要搜索；当前/此前/下一/更后连续分列 |
| 详情 | 快捷完成/回退缺失 | 保存当前表单草稿后留在同一详情，手记保留；原三观察状态收进更多选项，日期随状态显示 |
| 撤销 | 所有视图独占正文行 | 普通视图底部紧凑提示，下一步紧随图例；原有字段级并发保护保留 |
| 备份 | 缺少完成/手记摘要及同步入口 | 增加本版计数、本机保存状态和全站同步入口 |
