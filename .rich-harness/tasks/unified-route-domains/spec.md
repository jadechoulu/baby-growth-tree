# 三条作者路线与听说读写统一组织

2026-10-29

每位作者只有一条路线，统一按听力、口语、阅读、写作查看。移除许密杉四份资料选择，领域主节点与补充执行表分别关联，旧阶段、素材和来源完整保留。

许密杉以全景图组织四领域，听力第一阶段闪卡与绘本并行；执行表按领域补充做法，不改其500词目标或阶段号。香蕉妈妈按原计划年龄输出栏关联跟读和自拼；庆爸资料为听力专项，不要求跟读、复述。两者未展开的领域不补造阶段。领域对照不借用听力阶段，无阶段作者展示原文方法。原始资料在出处区查看，不再要求家长选版本。

领域组织放在 `english/data/route-plan.json`，通过 `getRoutePlan()` 解析；共享导航、宝宝推荐、个人记录与原素材排序保持不变。普通页面、单文件导出和统一站点同步构建。验收覆盖四领域、独立排列与阶段对照、补充执行任务、原页预览及全部代表宽度。
