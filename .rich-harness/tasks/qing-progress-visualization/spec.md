# 庆爸投入复盘

参考用户提供的 iHour 截图，默认看当前阶段，可切全路线；统一日期范围和有效/实际口径。用每日、每周、每月、每年堆叠趋势，环图与素材排行，以及可翻月日历复盘投入。窄屏以视图标签切换压缩阅读长度，长素材名完整换行。

图与排行颜色一致；图上时间段、素材、日期可筛选明细。日期可预填新增记录，编辑删除撤销沿用原持久保存与同步契约。筛选只影响浏览，不改记录或能力阶段。历史补录仅是已折算时长，实际口径排除并说明；零有效记录仍可查看。不同阶段的稳定素材键不按名称合并。无记录时展示空态和记录入口。

验收：日期和周/月/年边界、统计口径、阶段隔离、编辑撤回后重算；实际点击筛选、图表、日期、录入和编辑；320/375/390/768/900/901/1280宽度及许密杉回归。只本地实现，不提交发布。
