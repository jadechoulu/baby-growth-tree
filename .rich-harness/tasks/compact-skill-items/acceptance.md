# 成长技能项紧凑分列

## 目标与实现

- 技能名称与完整脉络入口紧邻，取消名称按钮撑满整行及重复的详情箭头。名称打开详情，脉络入口打开该技能的完整脉络，保留各自稳定 ID 和事件。
- 清单按实际内容容器宽度自动分列，最小项宽 144px，容器超过 700px 后使用至少 180px 的项宽；极窄屏退回单列。长名称和分类辅助文字可换行。
- 视口不超过 900px，或正文容器不超过 700px 时，脉络入口只显示图标，保留完整 aria-label 和悬停提示。完成圆按钮保持 18×18px，其他操作保持至少 44px。
- 分类辅助文字另起一行，收紧技能项上下留白；正文 15px，辅助文字 12px。不改记录、完成、回退及手记存储。

## 验收结果

- 在当前成长 worktree 的 5318 服务验收，不修改另一 worktree 的 5317 页面。
- 19–24个月四领域覆盖 320、375、390、580、768、900、901、1280px 共 32 组，技能内部无横向截断，名称与脉络入口之间无弹性空栏，完成按钮始终 18px。
- 13–18个月感知觉长名称另覆盖八档宽度。最终列数：320px 单列；375/390px 双列；580px 三列；768px 三列；900/901px 四列；1280px 五列。宽屏侧栏改变正文可用宽度后仍按容器分列。
- 点击“单脚踢球”打开对应解释与手记详情；点击旁边脉络图标直接打开“单脚踢球”的完整脉络。
- 领域清单收起后切换领域仍收起；重新展开、切换阶段和搜索“单脚”正常，清空搜索恢复完整清单。
- JavaScript 语法检查、15 项图谱/发布构建测试通过，统一站点构建通过。不新增纯展示镜像测试。
- 手机双列和 580px 三列截图保存在用户指定的育儿 codex 目录。按用户最新要求，变更只保留本地，等待明确“提交合并”指令。
