# 许密杉SSS必备歌单进度

日期：2026-11-03。状态：本地实现与下述验收已完成；未提交或发布。

## 目标与边界

许密杉进度中“SSS 指令式儿歌”等关联到已有SSS歌库的素材，点击名称直接打开原歌单弹窗的`essential`“必备10首”，通过单曲勾选记录，行内显示完成首数、百分比和细进度条，不再要求手填百分比。当前数据分母为10首，读取现有歌单定义，不在页面另抄一份歌名。

“必备”是用户指定的个人记录口径，不补造作者原文要求或词汇阶段晋级条件。仅指定的许密杉SSS素材使用此派生结果；庆爸SSS任务、SSS套系状态与其他素材维持原逻辑。阶段统计与列表、状态筛选读取同一派生结果，不写入整阶段达标状态。

## 数据与交互契约

- 单曲仍以`practice.song.v1:<songId>`保存，done表示完成，撤回保留not-started墓碑；同步与备份保留完整records和未知键。
- 纯汇总逻辑取`essential.songIds`中存在于歌库的去重ID；分母不受弹窗筛选、其他歌单或跨歌单重复影响。全部完成才显示100%，缺歌单或零有效歌曲不视为完成。
- 汇总不修改输入records，也不写回`practice.material.v1:`；旧素材状态、手填百分比、日期、备注和未知元数据继续保留，不反推单曲状态。
- 从本素材进入时明确选择必备歌单，并清除妨碍必备清单完整展示的旧筛选；其他原有歌单入口不无故重置其浏览状态。
- 勾选成功后刷新底层许密杉汇总与当前歌单状态，不重建弹窗，保留焦点、场景筛选和滚动；保存失败不显示完成。
- 标题、用途、完成数量／总首数、进度条和百分比保持紧凑同行，长标题自然换行，不恢复独立大块表单或日期行。

## 验收契约

1. 模型验证0/10→0%、1/10→10%、10/10→100%，撤回一首回到90%；仅完成非必备歌曲不改变结果。
2. 重复ID不增加分母、未知歌曲ID不计数、缺歌单不产生100%；汇总不修改原记录，旧素材完成不能直接产生单曲完成。
3. 从许密杉素材打开即显示必备10首；勾选后关闭弹窗，素材与阶段汇总更新；再次打开及刷新后保留状态。
4. 其他歌单可记录，非必备歌曲不改变该素材进度；庆爸任务与整套状态不受影响。
5. 实际操作勾选与撤回，确认弹窗焦点、筛选、滚动和关闭后入口恢复；保存失败不出现成功状态。
6. 普通入口与单文件入口构建一致；代表宽度320／375／390／768／900／901／1280px中内容完整、无主体溢出，进度条不独占一整行。
7. 运行相关模型测试、英语构建与页面检查；涉及共用发布构建时串行执行，保留累计未提交改动，不自动提交或发布。模型或本机验证不冒充真实跨设备验收。
