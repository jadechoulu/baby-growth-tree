# 素材图鉴数量范围修复

本地实现，未提交、未发布。数量与目录覆盖分开：选择路线、阶段时取同一原始引用的交集，再按版本与分项去重累加；未筛选时汇总当前已核各版本范围。未核实级别不按0本表示，也不借其他版本的目录充当该范围总量。

卡片已核数量由 `EnglishLibraryBooks.seriesCount()` 统一派生。数量表中的同一分项即使被单辑、组合或级别入口重复列出也只计一次；按现有级别模型展开1–3，不能给“虚构部分”等限定选材直接借用整级册数。

有路线/阶段条件时读取现有进度页实际选用范围：许密杉当前0–300词的大猫默认粉色44本，切换到外研预备级变为18本；新版培生默认96本，切换旧三辑为96本。只读取已有记录与默认选择，不写个人记录。`resource-volumes.json` 中的 `directoryMatch` 显式关联选版分项和目录版本，不从相似名称推定版本等价。

点击册数先显示当前筛选、各版本数量构成、待核范围、完整目录收录数及当前可对应条数，再展示当前版本目录。没有明确总量来源时，卡片使用“已收录N本”的目录口径，不声称全套总数。之前选中的目录版本在新筛选下不存在时重置为“全部版本”，避免无故空白。
