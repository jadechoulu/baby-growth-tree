# 当前年龄选择路线case

用户要求：香蕉妈妈及其他路线存在多种case时，统一以宝宝当前年龄选择，不能混用不同年龄的阅读量、节奏、输出及自拼时机。

- 月龄依据共享生日和上海当前日期；年龄case使用显式月龄范围和稳定ID，不能从阶段最早月龄或书目倒推。
- 当前case供卡片、详情、配套输出/自拼、年龄关系页统一使用；其他case只作折叠原文参考，原始来源数据保留。
- 当前未满2岁，仅将2/3岁香蕉表标为低龄参考，不把原表用量直接排为宝宝任务。庆爸3/4岁资料单独标适用范围。无年龄case的许密杉不补造年龄门槛。
- 日期变化重新可见时重算；共享资料变动后刷新阶段内容，保护个人领域记录。
- 能力阶段及阶段对应不因年龄case变化自动晋级；非零基础按实际理解和原文条件切入。
- 验收包含年龄边界、来源页、输出和自拼分支隔离、未来路线复用及移动端阅读。日常保持本地未提交。
